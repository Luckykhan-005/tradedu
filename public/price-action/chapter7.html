باب ۷: Price Action Strategy

۱. Strategy Overview

مارکیٹ سٹرکچر + Order Blocks + FVG + Liquidity = مکمل سٹریٹجی۔ بغیر انڈیکیٹرز کے صرف price سے ٹریڈ کریں۔

۲. Entry Checklist

#شےوضاحت
۱HTF ٹریڈنگDaily/4H سٹرکچر دیکھیں
۲Key LevelS/R, Order Block, FVG
۳CHoCH/BOSLTF میں تبدیلی
۴Liquidity Sweepسٹاپ ہنٹ ہوا؟
۵RR 1:2+-risk reward ratio

۳. Confluence

جب 3+ چیزیں ایک ساتھ ملیں — مضبوط ترین entry۔ مثال: Order Block + FVG + Liquidity Sweep = بہترین entry۔

۴. Example Setup

Bullish Setup:
1. Daily: Bullish ٹریڈنگ (HH/HL)
2. 4H: Bullish Order Block نزدیک
3. 1H: Bearish CHoCH — قیمت نیچے آئی
4. 15M: Liquidity sweep ہوا
5. Entry: Order Block + FVG zone
6. SL: Order Block کے نیچے
7. TP: 1:2+ RR
