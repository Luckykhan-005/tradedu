باب ۴: Order Blocks

۱. آرڈر بلاک کیا ہے؟

English: Order Block

وہ زون جہاں بڑے سرمایہ کاروں (سمارٹ منی) نے بڑے آرڈرز لگائے — قیمت تیزی سے حرکت کری۔ یہ سپورٹ/ریزسٹنس کے زیادہ مضبوط ہوتے ہیں۔

۲. Bullish Order Block

ڈاؤن ٹریڈنگ میں آخری سُرخ کینڈل — جس کے بعد قیمت تیزی سے بڑھی۔ یہ خرید کا زون ہے۔

۳. Bearish Order Block

اپ ٹریڈنگ میں آخری سبز کینڈل — جس کے بعد قیمت تیزی سے گری۔ یہ فروخت کا زون ہے۔

۴. Order Block Mitigation

جب قیمت واپس آ کر order block کو چھوئے — mitigation ہوتا ہے۔ اس کے بعد order block کمزور ہو جاتا ہے۔

۵. Order Block Entry

Order block کے قریب آئے — CHoCH/BOS دیکھیں — entry لیں — SL order block کے نیچے رکھیں۔

🔑 اہم نکات

Order blocks S/R سے زیادہ مضبوط ہیں۔

Mitigation کے بعد order block کمزور ہوتا ہے — نئے دھونڈیں۔

SL ہمیشہ order block کے پیچھے رکھیں۔
