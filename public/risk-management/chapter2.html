باب ۲: Position Sizing

۱. Position Sizing کیا ہے؟

English: Position Sizing

ہر ٹریڈ میں کتنا پیسہ لگائیں — یہ حساب لگانے کا عمل۔

۲. Fixed Percentage Rule

ہر ٹریڈ میں اکاؤنٹ کا صرف 1-2% رسک لیں۔

مثال: اکاؤنٹ ,000 — 1% = max loss per trade۔ اگر SL کی دوری پر ہے — 0.5 lot سے زیادہ نہ لیں۔

۳. Formula

Position Size = (Account × Risk%) / (Entry - SL)

اکاؤنٹRisk%SL DistanceSize
,0001%/ = 1 lot
,0002%/ = 1 lot
,0001%/ = 1 lot

۴. Scaling

جب اکاؤنٹ بڑھے — size بھی بڑھے۔ جب گھٹے — size کم ہو۔ ہمیشہ 1-2% rule follow کریں۔

🔑 اہم نکات

1% rule — سب سے اہم rule — کبھی نہ توڑیں۔

Size SL distance سے نکالیں — entry سے نہیں۔
