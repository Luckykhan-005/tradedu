باب ۸: Equity Curve

۱. Equity Curve کیا ہے؟

English: Equity Curve

اکاؤنٹ کی قیمت کا graph — اوپر جا رہا = اچھا — نیچے جا رہا = خطرہ۔

۲. Smooth Curve

بہترین curve: آہستہ اوپر — چھوٹے چھوٹے نقصان — بڑا نقصان نہیں۔

۳. Volatile Curve

خراب curve: بڑی نشانیاں — بڑا منافع — بڑا نقصان — ذہنی دباؤ۔

۴. Curve Monitoring

Curve نیچے جا رہا ہو = position size آدھی — 5% drawdown = آج بس — 10% = ہفتہ بند۔

🔑 اہم نکات

Smooth curve > بڑا منافع۔

Curve down = کم ٹریڈ — کم size — صبر۔
