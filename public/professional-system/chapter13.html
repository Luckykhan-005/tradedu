باب ۱۳: Scaling

۱. Scaling kya hai?

English: Scaling Up

Consistent profit ke baad — gradually account aur size barhana. Achanak nahi — ahista ahista.

۲. Kab Scale Karein?

#Condition
۱6 months+ consistent profit
۲Rules 100% follow
۳Drawdown under control
۴Journal consistently maintained
۵Psychology under control

۳. Kaise Scale Karein?

Account double karo → size double karo. Phir 6 months wait. Phir double. Ahista ahista.

۴. Scaling Warning

Agar rules todne lage — size wapas chhota karo. Scaling loss se pehle roko.

🔑 Ahm Nuktaat

Scaling = reward — pehle consistent bano.

Achanak mat barhao — gradual growth.

Rules barhi size ke saath bhi same honi chahiye.
