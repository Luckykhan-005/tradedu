ب: اہم فارمولے (Formulas)

یہ حصہ ٹریڈنگ کی ریاضی ہے۔ ہر فارمولے کے ساتھ عملی مثال دی گئی ہے تاکہ آپ اسکرین پر موجود اعداد و شمار خود نکال سکیں۔ فارمولے سمجھنا منافع اور نقصان کے درمیان فرق ہے۔

1. منافع اور نقصان کا فیصد

فیصد تبدیلی = (موجودہ قیمت - خرید قیمت) / خرید قیمت × 100

مثال (منافع):

خرید: $60,000 → فروخت: $66,000
منافع = (66,000 - 60,000) / 60,000 × 100 = 10%

مثال (نقصان): خرید $60,000 → فروخت $54,000 = -10%

اگر فیچرز/لیوریج استعمال ہو تو فیصد منافع = قیمت کی تبدیلی × لیوریج۔

2. رفتار خطرہ-منافع (R:R)

R:R = متوقع منافع / متوقع نقصان

مثال:

داخلہ: $60,000   اسٹاپ: $58,000 (خطرہ $2,000)
ٹارگٹ: $68,000  (منافع $8,000)
R:R = 8,000 / 2,000 = 4:1

اصول: کم از کم 2:1 سے شروع کریں — ورنہ کم جیتنے کے باوجود مجموعی منافع مشکل ہے۔

3. اسٹاپ لاس اور ٹیک پروفیٹ (قیمت)

Long:  اسٹاپ لاس = داخلہ × (1 - Risk%)
Long:  ٹارگٹ    = داخلہ × (1 + Reward%)
Short: اسٹاپ لاس = داخلہ × (1 + Risk%)
Short: ٹارگٹ    = داخلہ × (1 - Reward%)

مثال (Long، 3% اسٹاپ): داخلہ $60,000 → اسٹاپ = 60,000 × 0.97 = $58,200

4. پوزیشن سائز (Position Sizing) — سب سے اہم

خطرے کی رقم = کل سرمایہ × رسک %
پوزیشن سائز = خطرے کی رقم / (داخلہ - اسٹاپ)

مثال:

کل سرمایہ: $1,000   رسک: 1% = $10
داخلہ: $60,000   اسٹاپ: $59,000 → فرق = $1,000
پوزیشن سائز = 10 / 1,000 = 0.00001 BTC

قاعدہ: پہلے خطرہ طے کریں، پھر مقدار — نہ کہ اُلٹا۔

5. اوسط قیمت (DCA / اکاؤنٹنگ)

اوسط قیمت = کل خریداری لاگت / کل مقدار

مثال:

خرید 1: $100 @ $25,000 = 0.004 BTC
خرید 2: $100 @ $20,000 = 0.005 BTC
کل: $200 / 0.009 = $22,222 اوسط

اوسط قیمت مقدار کے حساب سے ہوتی ہے — مختلف قیمتوں کا سادہ اوسط غلط ہے۔

6. لیوریج اور مارجن

مارجِن (Margin) = پوزیشن کی مالیت / لیوریج
قیمت کی فیصد حرکت = PnL فیصد / Leverage

مثال:

پوزیشن: $10,000 @ 10x لیوریج → مارجن = $1,000
قیمت 5% بڑھی → منافع ≈ 50% مارجن ($500)
قیمت 5% گری  → نقصان ≈ 50% مارجن ($500)

لیوریج منافع اور نقصان دونوں کو اتنا ہی بڑھاتا ہے۔

7. لیکویڈیشن کا تخمینہ (Isolated، سادہ)

لگ بھگ لیکویڈیشن فاصلہ (%) ≈ 100 / Leverage

مثال:

10x → تقریباً 10% حرکت پر لیکویڈیشن
50x → صرف 2% حرکت پر لیکویڈیشن
100x → صرف 1% حرکت پر

یہ تخمینی ہے — اصل مارجن فیصد اور فیس سے فرق ہوتا ہے۔ اسے اسکرین پر "Lik. Price" سے تصدیق کریں۔

8. ٹریڈ فیس

فیس = ٹریڈ کی مالیت × فیس شرح
Maker فیس < Taker فیس

مثال:

ٹریڈ: $5,000   Taker: 0.10%  → فیس = $5
اگر VIP/BNB سے 0.075% → فیس = $3.75 (25% بچت)

9. سٹیکنگ/Earn کا انعام

سادہ (APR):  انعام = رقم × APR × (دن / 365)
مرکب (APY):  سالانہ رقم = رقم × (1 + r/n)^n

مثال (APY 10%، ماہانہ کمپاؤنڈ):

رقم = $1,000، r = 0.10، n = 12
سالانہ = 1000 × (1 + 0.10/12)^12 ≈ $1,104.71

APR یکساں نہیں APY — کمپاؤنڈنگ کی وجہ سے APY تھوڑا زیادہ ہوتا ہے۔

10. گرڈ ٹریڈنگ میں ہر گرڈ کا فاصلہ

ہر گرڈ کا فاصلہ = (بالائی حد - زیریں حد) / گرڈ کی تعداد

مثال: $62,000 تا $68,000، 6 گرڈ → ہر گرڈ فاصلہ = $1,000

11. بریک ایون (شامل فیس)

بریک ایون قیمت = (کل لاگت + فیسیں) / کل مقدار

مثال: $10,000 + $20 فیس میں 0.2 BTC → بریک ایون ≈ $50,100

12. کمپاؤنڈ سالانہ شرح (CAGR)

CAGR = (اختتامی قدر / ابتدائی قدر)^(1/سال) - 1

مثال: $1,000 → $1,210 دو سال میں → (1.21)^0.5 - 1 = 10% سالانہ

⚠️ نوٹ

  • ساری مثالیں تعلیمی ہیں؛ اصلی مارکیٹ میں slippage، فیس اور فنڈنگ بدلتے رہتے ہیں۔
  • ہر فارمولہ پہلے Demo/چھوٹے ٹریڈ پر آزما لیں۔

✅ خلاصہ

  • R:R اور Position Size بنیادی ہیں — باقی سب اُن کے بعد۔
  • اوسط قیمت = کل لاگت ÷ کل مقدار (سادہ اوسط غلط)۔
  • لیوریج منافع و نقصان دونوں کو بڑھاتا ہے؛ لیکویڈیشن ≈ 100/لیوریج۔
  • APY ≠ APR — APY میں کمپاؤنڈ شامل ہے۔

📝 عملی مشق

  1. $2,000 سرمایہ، 1% رسک، داخلہ $50,000، اسٹاپ $49,000 — پوزیشن سائز نکالیں۔
  2. 10x لیوریج پر 3% قیمت کی حرکت سے مارجن پر منافع/نقصان (%) حساب کریں۔
  3. APY 8% ماہانہ کمپاؤنڈ پر $500 کی سالانہ قدر نکالیں۔
  4. دو مختلف قیمتوں پر DCA کر کے اوسط نکالیں (مقدار کے ساتھ)۔

🧠 یاد رکھیں

"پہلے خطرہ (Risk)، پھر سائز (Size)، پھر منافع (Reward)۔" جس کے پاس فارمولے ہیں، وہ اندازے پر نہیں، حساب پر ٹریڈ کرتا ہے۔
