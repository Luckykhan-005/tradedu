باب 8: پروفائل اور سیٹنگز — ہر آپشن کی مکمل تفہیم

پروفائل آپ کا کنٹرول سینٹر (Control Center) ہے — یہاں آپ کی سب سے اہم سیٹنگز، سیکیورٹی کے اوزار، اور اکاؤنٹ کے تمام اختیارات ایک جگہ موجود ہوتے ہیں۔ یہ باب ہر آپشن کو تفصیل سے سمجھاتا ہے — تاکہ آپ اپنے اکاؤنٹ کو نہ صرف استعمال کریں، بلکہ اسے مکمل کنٹرول کریں۔

🎯 اس باب میں آپ سیکھیں گے

  • پروفائل مینو کا مکمل نقشہ
  • User Center — اکاؤنٹ ڈیش بورڈ
  • زبان، تھیم اور اکاؤنٹ کی بنیادی تبدیلیاں
  • سیکیورٹی سینٹر کے ہر آپشن کا مطلب اور ترجیح
  • سیکیورٹی اسکور — 100/100 کا ہدف
  • ٹرانزیکشن ہسٹری کو صحیح طریقے سے دیکھنا
  • API مینجمنٹ کا محفوظ استعمال (جان بچانے کے اصول)
  • Sub-Accounts (ذیلی اکاؤنٹس) کب اور کیوں
  • Referral پروگرام

📖 8.1 پروفائل مینو کہاں ملتا ہے؟

اوپر والی نیویگیشن بار کے دائیں کونے میں 👤 (پروفائل آئیکن) پر کلک کریں — ڈراپ ڈاؤن کھل جائے گا:

👤 [اکاؤنٹ آئیکن] ▾
├── User Center              (اکاؤنٹ ڈیش بورڈ)
├── Settings                 (بنیادی سیٹنگز)
├── Security                   (سیکیورٹی سینٹر)
├── Identification / KYC     (شناخت کی تصدیق)
├── API Management           (API چابیاں)
├── Sub-Accounts             (ذیلی اکاؤنٹس)
├── Transaction History      (لین دین کی تاریخ)
├── Referral                 (ریفرل پروگرام)
├── Help / Support           (مدد)
└── Log Out                  (لاگ آؤٹ)

💡 بعض اکاؤنٹس میں یہ اختیارات "More" یا "•••" کے پیچھے چھپے ہوتے ہیں۔

📖 8.2 User Center — اکاؤنٹ ڈیش بورڈ

User Center آپ کا ایک جگہ پر مکمل خلاصہ ہے — بیلنس، آرڈرز، پوزیشنز اور اکاؤنٹ کی حالت۔

سیکشنکیا دکھاتا ہے
Balancesتمام وولیٹس کا بیلنس اور Estimate Value
Open Ordersابھی تک غیر مکمل آرڈرز
Positionsکھلی فیوچرز پوزیشنز
P&Lمنافع / نقصان
Recent Activityتازہ ترین کارروائیاں
KYC Statusشناخت کی تصدیق کا درجہ
Security Statusسیکیورٹی کا مکمل جائزہ

💡 یہ آپ کی روزانہ کی پہلی اسکرین ہونی چاہیے — ایک نظر ڈال لیں کہ سب ٹھیک ہے، پھر ٹریڈنگ شروع کریں۔

📖 8.3 Settings — بنیادی سیٹنگز

8.3.1 Language (زبان)

  • بائننس 40+ زبانیں سپورٹ کرتا ہے
  • تبدیلی فوری لاگو ہوتی ہے
  • کچھ اصطلاحات (جیسے "Maker/Taker") ہر زبان میں ترجمہ نہیں ہوئے، اس لیے انگریزی بھی سیکھنا مفید ہے

8.3.2 Theme (تھیم)

تھیممقصد
Lightدن کے وقت واضح
Darkرات میں آنکھوں کو راحت؛ پروفیشنل تاجر عموماً یہی استعمال کرتے ہیں
Systemڈیوائس کی سیٹنگ کی پیروی

8.3.3 Email / Phone تبدیل کرنا

  • نیا ای میل یا فون نمبر تصدیق کرنا لازمی ہے
  • تبدیلی کے بعد سیکیورٹی سٹیٹس عارضی طور پر "Pending" میں آ سکتا ہے
  • ⚠️ اہم: رقم نکالنے کی سہولت کچھ وقت کے لیے (عموماً 24 گھنٹے) معطل ہو سکتی ہے — دھوکہ دہی سے بچنے کے لیے

8.3.4 Password (پاس ورڈ)

  • مضبوط پاس ورڈ: کم از کم 12 حروف، بڑی/چھوٹی حروف، اعداد، علامات
  • ⚠️ پاس ورڈ تبدیل کرنے کے بعد 2FA دوبارہ سیٹ کرنا پڑ سکتا ہے
  • پاس ورڈ کہیں محفوظ رکھیں، نہ کہ براؤزر میں — پاس ورڈ مینیجر استعمال کریں (Bitwarden، 1Password)

📖 8.4 Security Center — آپ کا سب سے اہم حصہ

یہ وہ جگہ ہے جہاں آپ اپنے اکاؤنٹ کی حقیقی حفاظت کرتے ہیں۔ بائننس ہر ترتیب کو "فعال/غیر فعال" کے ساتھ دکھاتا ہے۔

سیکیورٹی سینٹر کے اہم اوزار:

آپشنکیا کرتا ہےترجیح
2FA (Google Authenticator)لاگ اِن و وِڈراول پر 6 ہندسوں کا کوڈ🔴 لازمی
SMS / Email Verificationبیک اپ تصدیق🟠 اہم
Anti-Phishing Codeآپ کی ای میلز میں جانا پہچانا کوڈ🟠 اہم
Address Whitelistصرف منظور شدہ ایڈریس پر وِڈراول🟢 مفید
Device Managementتمام لاگ اِن ڈیوائسز کی فہرست🟠 اہم
Login Historyلاگ اِن ریکارڈ🟢 مفید
Passkey (2025+)بائیو میٹرک/ہارڈ ویئر کی لاگ اِن🟢 جدید
Fund Passwordرقم کی منتقلی کا الگ پاس ورڈ🟠 اہم

سیکیورٹی اسکور:

🔒 Security Score: 75/100
✅ 2FA فعال
✅ Anti-Phishing کوڈ سیٹ
❌ Withdrawal Whitelist غیر فعال
✅ مضبوط پاس ورڈ
⚠️ غیر ضروری ڈیوائسز فعال

🎯 ہدف: 100/100 — ہر اوزار جو فعال ہوتا ہے، اکاؤنٹ ہیک کے لیے مشکل ہو جاتا ہے۔

Passkey — جدید لاگ اِن (2025+)

Passkey ایک جدید طریقہ ہے جو آپ کے فون کے فنگر پرنٹ، چہرہ، یا PIN سے لاگ اِن ہوتا ہے — پاس ورڈ سے زیادہ محفوظ (کیونکہ فشنگ سے نہیں چرا سکتے)۔

مقابلہپاس ورڈPasskey
فشنگ❌ چور ہو سکتا ہے✅ ناممکن
یاد رکھنا❌✅
ڈیوائسکہیں سےاسی ڈیوائس سے

📖 8.5 Transaction History — ہر کارروائی کا ریکارڈ

Transaction History آپ کے اکاؤنٹ کی مکمل ڈائری ہے — کبھی بھی کسی بھی لین دین کی تصدیق کے لیے یہاں دیکھیں۔

دستیاب فلٹرز:

فلٹرکیا دکھاتا ہے
Spotصرف Spot ٹریڈز
Marginصرف مارجن ٹریڈز
Futuresصرف فیوچرز ٹریڈز
Earnسٹیکنگ و منافع
Depositباہر سے آئی رقم
Withdrawباہر بھیجی رقم
Transferاندرونی منتقلی
Convertسواپس

ہر ٹرانزیکشن کی تفصیل:

  • Transaction ID (TxID) — ایک منفرد نمبر (بلاک چین پر ٹریک کے لیے)
  • Time — تاریخ اور وقت
  • Type — لین دین کی قسم
  • Amount — مقدار اور کوائن
  • Status — Completed / Pending / Failed
  • Fee — لگی فیس

💡 مشورہ: ہر ہفتے ایک بار تاریخ چیک کریں۔ اگر کوئی اجنبی لین دین نظر آئے تو فوراً:

  1. پاس ورڈ تبدیل کریں
  2. 2FA دوبارہ سیٹ کریں
  3. سپورٹ سے رابطہ کریں

📖 8.6 API Management — خودکار ٹریڈنگ کی چابیاں

API کیا ہے؟

API (Application Programming Interface) ایک "پُل" ہے جو باہر کے پروگرامز/بوٹس کو آپ کے بائننس اکاؤنٹ سے جوڑتا ہے۔ API کلید تمام معلومات نہیں دیتی — آپ خود فیصلہ کرتے ہیں کہ کیا اجازت ہوگی۔

API کلید بناتے وقت:

آپشنوضاحتمشورہ
Labelکلید کا نامنیت کے مطابق رکھیں (مثلاً "GridBot")
Readبیلنس/آرڈرز پڑھناضرورت کے مطابق
Spot/Margin Tradingٹریڈز لگاناصرف ضرورت پر
Futures Tradingفیوچرزصرف ضرورت پر
Withdrawalsرقم نکالنا🔴 کبھی فعال نہ کریں
IP Restrictionصرف مخصوص IPs🔴 لازمی

📌 سونے کے اصول:

  1. Withdrawal کی اجازت والی API کلید کبھی نہ بنائیں۔
  2. IP Restriction ہمیشہ لگائیں — اس کے بغیر کلید لیک ہو تو کوئی بھی ٹریڈ کر سکتا ہے۔
  3. کلید کو گزیدہ (Plain) کسی کو نہ دیں — یہاں اسکرین شاٹ لے کر شیئر کرنے والے اکثر دھوکہ کھاتے ہیں۔
  4. جب ضرورت نہ رہے تو کلید حذف کر دیں۔
  5. بوٹ/سگنل پرووائیڈر کو API کلید دیتے وقت اضافی احتیاط کریں۔

⚠️ حقیقت: اگر آپ API کلید کسی کو دیتے ہیں، تو آپ اپنے اکاؤنٹ کی چابی دے رہے ہیں۔ جو بھی کہے "مجھے API دو، میں آپ کے لیے ٹریڈ کروں گا" — وہ دھوکے باز ہو سکتا ہے۔

📖 8.7 Sub-Accounts — ذیلی اکاؤنٹس

Sub-Account کیا ہے؟

Sub-Account آپ کے مرکزی اکاؤنٹ کے اندر الگ اکاؤنٹ ہے — اس کے اپنے بیلنس، اپنے آرڈرز اور محدود اجازتیں (Permissions) ہوتی ہیں۔

Sub-Account کے اجازتیں:

اجازتمطلب
Spot Tradingذیلی اکاؤنٹ Spot ٹریڈ کر سکتا ہے
Margin Tradingمارجن ٹریڈ
Futures Tradingفیوچرز ٹریڈ
Transferاپنے اور مرکزی اکاؤنٹ کے درمیان منتقلی
Virtual Sub-Accountصرف API کے لیے

کب استعمال کریں:

  • ٹیم/کمپنی کے مختلف ارکان کے فیصلے الگ رکھنے کے لیے
  • مختلف حکمت عملیوں (Strategies) کے لیے الگ بیلنس
  • مرکزی اکاؤنٹ کی حفاظت کے لیے — ذیلی اکاؤنٹ میں رقم کی واپسی محدود رہتی ہے

📖 Sub-Accounts کی مکمل تفصیلی گائیڈ: باب 55

📖 8.8 Referral — دوست بلائیں، انعام پائیں

بائننس کا Referral Program دوستوں کو مدعو کرنے پر انعام دیتا ہے۔

  • آپ کی ذاتی ریفرل لنک/کوڈ حاصل کریں
  • دوست رجسٹر ہو کر جب ٹریڈ کرے، آپ کو کمیشن ملتا ہے
  • ریفرل کی تفصیلات اور کمیشن اسی صفحے پر دکھائی دیتے ہیں

⚠️ یاد رکھیں: کسی کو کوڈ لگوانے کے لیے منافع کی گارنٹی مت دیں — یہ آپ کی ذمہ داری ہے۔

📖 Referral اور VIP کی تفصیلی گائیڈ: باب 60

⚠️ عام غلطیاں

  1. سیکیورٹی سینٹر کو نظر انداز کرنا — ہر ماہ چیک کریں اور اسکور 100% کے قریب رکھیں۔
  2. پاس ورڈ / فون نمبر تبدیل کرنے کے بعد 2FA دوبارہ سیٹ نہ کرنا — ایک نقصان بن جاتا ہے۔
  3. API کلید میں Withdrawal اجازت دینا — یہ سب سے بڑا خطرہ ہے۔
  4. API کلید کو IP Restriction کے بغیر چھوڑنا — لیک ہونے پر اکاؤنٹ خالی ہو سکتا ہے۔
  5. Transaction History نہ دیکھنا — اجنبی لین دین جلدی پکڑیں۔
  6. Sub-Account بغیر وجہ بنانا — صرف ضرورت پر آپشن استعمال کریں۔
  7. پاس ورڈ براؤزر/نوٹ پیڈ میں محفوظ کرنا — پاس ورڈ مینیجر استعمال کریں۔
  8. Passkey کو نظر انداز کرنا — یہ پاس ورڈ سے زیادہ محفوظ ہے۔
  9. جوئے والی ای میل کو اکاؤنٹ سے جوڑنا — ای میل الگ اور محفوظ رکھیں۔

✅ خلاصہ

  • پروفائل = کنٹرول سینٹر — تمام اہم اختیارات یہیں
  • User Center = روزانہ کی پہلی اسکرین
  • Security Center = سب سے اہم حصہ؛ اسکور 100% کا ہدف
  • Transaction History = ہر لین دین قابلِ تصدیق
  • API = طاقتور مگر خطرناک؛ Withdraw اجازت کبھی نہ دیں
  • Sub-Accounts = ٹیم/حکمت عملیوں کے لیے
  • Referral = دوستوں کو بلانے پر کمیشن
  • Passkey = پاس ورڈ سے زیادہ محفوظ، اسے فعال کریں

📝 عملی مشق

  1. 👤 پروفائل پر کلک کریں اور User Center کا جائزہ لیں۔
  2. Security Center کھولیں اور اپنا سیکیورٹی اسکور لکھیں۔
  3. ایک ایک اوزار چیک کریں: 2FA، Anti-Phishing، Whitelist، Device Management، Passkey۔
  4. Settings → Language میں اردو (اگر دستیاب) منتخب کر کے دیکھیں۔
  5. Settings → Theme میں Dark تھیم آزمائیں۔
  6. Transaction History کھول کر ایک ڈیپازٹ کی TxID کاپی کریں (بغیر شیئر)۔
  7. API Management دیکھیں — کلید نہ بنائیں، صرف صفحے کے اختیارات پڑھیں۔
  8. Referral صفحہ دیکھیں — اپنا کوڈ نوٹ کریں (کسی کو مت دیں ابھی)۔
  9. اگر اکاؤنٹ موجود ہو تو سیکیورٹی اسکور بڑھائیں — کم از کم 2FA اور اینٹی فلشنگ کوڈ فعال کریں۔

🧠 یاد رکھیں

پروفائل گاڑی کا ڈیش بورڈ ہے۔ جیسے گاڑی میں اسپیڈومیٹر، فیول گیج اور وارننگ لائٹس ایک جگہ ہوتی ہیں، ویسے ہی پروفائل میں آپ کے اکاؤنٹ کی تمام اہم معلومات موجود ہوتی ہیں۔ اور سیکیورٹی سینٹر گاڑی کے بریک ہیں — جتنی مضبوط سیکیورٹی، اتنا محفوظ سفر۔

بریک چیک کیے بغیر گاڑی نہ چلائیں؛ سیکیورٹی چیک کیے بغیر اکاؤنٹ نہ رکھیں۔ اور یاد رکھیں — API کلید = اکاؤنٹ کی چابی۔ جسے چابی دیں، اسے اپنا گھر دیتے ہیں۔
