باب 43: موبائل وولیٹ — فنڈز کا انتظام

Wallet بائننس (بائننس کسٹوڈیل) کا وہ حصہ ہے جہاں آپ کے اثاثے محفوظ رہتے ہیں۔ نوٹ کریں: 2025 کے بعد بائننس نے عام صارف کے لیے الگ "Funding Wallet" کا تصور آسان کر دیا ہے — ڈیپازٹ/وائیدراول اب Spot Wallet سے ہوتے ہیں، جبکہ Futures Wallet صرف ڈیریویٹوز ٹریڈنگ کے لیے الگ رہتا ہے۔

🎯 اس باب میں آپ سیکھیں گے

  • موبائل پر Spot Wallet اور Futures Wallet کا فرق
  • والیٹس کے درمیان فنڈز کی منتقلی (Transfer)
  • موبائل پر ڈیپازٹ (Crypto + Fiat) کا طریقہ
  • موبائل پر وائیدراول کا محفوظ طریقہ (Networks، Memo، Whitelist)
  • بیلنس کہاں دیکھیں اور "Available" بمقابلہ "In Order" کا مطلب
  • موبائل وولیٹ کے عام خطرات سے بچاؤ

📖 43.1 Spot Wallet بمقابلہ Futures Wallet

خصوصیتSpot WalletFutures Wallet
کس کے لیےخرید/فروخت، Earn، P2P، ڈیپازٹ/وائیدراولصرف Futures/Margin ٹریڈنگ
اثاثے کی قسماصل کرپٹو (حقیقی ملکیت)مارجن/کولیٹرل بیلنس (USDT عموماً)
وائیدراولہاں (بلاک چین/فیاٹ)نہیں — پہلے Spot میں منتقل کریں
دو ٹکڑے الفاظAvailable (استعمال کے قابل) + In Order (آرڈر میں بندھا)Wallet Balance + Available

منتقلی (Transfer)

Futures ٹریڈ کے لیے رقم Spot سے Futures میں لے جائیں:

Wallet → Transfer → From: Spot → To: Futures → رقم → Confirm

ٹریڈ ختم ہو تو واپس Spot میں لائیں:

Wallet → Transfer → From: Futures → To: Spot → Confirm

نوٹ: Futures Wallet سے براہِ راست کرپٹو وائیدراول نہیں ہو سکتا۔ پہلے Spot میں Transfer کریں، پھر Withdraw۔

📖 43.2 موبائل پر ڈیپازٹ

کرپٹو ڈیپازٹ

Wallet → Deposit → Crypto → کوائن منتخب (مثلاً USDT)
    → Network منتخب (مثلاً TRC20)
    → Address کاپی/QR اسکین
    → (اگر Memo/Tag ہو تو لازمی درج کریں)
    → بھیجنے والے پلیٹ فارم میں پیسٹ → Send

فیاٹ ڈیپازٹ (PKR کے لیے P2P)

Wallet → Deposit → Fiat → PKR → P2P طریقہ
    → سیلر منتخب → ادائیگی کریں → Crypto موصول

PKR کے لیے عموماً براہِ راست بینک ڈیپازٹ دستیاب نہیں؛ P2P ہی سب سے عام راستہ ہے۔

⚠️ طلائی اصول: جو Network بھیجنے والا پلیٹ فارم منتخب کرے، وہی بائننس پر منتخب کریں۔ نیٹ ورک غلط ہو تو فنڈز ہمیشہ کے لیے ضائع ہو سکتے ہیں۔

📖 43.3 موبائل پر وائیدراول (محفوظ طریقہ)

Wallet → Withdraw → کوائن منتخب → Network منتخب
    → Address (یا Saved Address سے منتخب)
    → اگر Memo/Tag لازمی ہو → درج کریں
    → مقدار درج → Preview/Confirm → 2FA → Submit

وائیدراول سے پہلے 3 جانچ

  1. ایڈریس — پہلے اور آخری 4 حروف موازنہ کریں۔
  2. نیٹ ورک — وصول کنندہ کے نیٹ ورک سے میل کھائے۔
  3. Memo/Tag — اگر وصول کنندہ (جیسے کچھ ایکسچینجز) مانگے تو لازمی بھرنا ہے۔

Address Whitelist: Security سیٹنگز میں Address Whitelist آن کریں — اس سے صرف منظور شدہ ایڈریس پر وائیدراول ممکن ہوگا، اور کسی ہیکر کو نیا ایڈریس شامل کرنے میں وقت لگے گا۔

Address Swapping کا خطرہ:

آپ ایڈریس کاپی کرتے ہیں: 0xABC...123
موبائل پر مالویئر خاموشی سے کلپ بورڈ بدل دیتا ہے:
                       0xXYZ...789 (ہیکر کا ایڈریس)
آپ پیسٹ کرتے ہیں → پیسہ ہیکر کو چلا گیا ❌

بچاؤ: پیسٹ کے بعد پہلے اور آخر کے حروف خود دیکھیں

📖 43.4 بیلنس کہاں دیکھیں؟

ایپ نیچے مینو → Wallet → Overview
    → کل تخمینہ (Estimated Value)
    → ہر کوائن کی Available اور In Order مقدار
    → Spot / Futures / Earn سب الگ الگ ٹیب
  • Available: فوری استعمال/وائیدراول کے قابل۔
  • In Order: کھلے آرڈرز میں بندھا (Limit آرڈر لگا ہو تو Available نہیں)۔
  • In Earn: Simple Earn/Staking میں جمع (Flexible تو جلد واپس، Locked مقررہ وقت)۔

⚠️ عام غلطیاں

  1. ❌ غلط نیٹ ورک منتخب کرنا — فنڈز ضائع ہو سکتے ہیں (سب سے خطرناک)۔
  2. ❌ Memo/Tag چھوڑ دینا جہاں لازمی ہو — کرپٹو رسید پر پہنچ کر بھی وصول کنندہ کریڈٹ نہیں کر پاتا۔
  3. ❌ Futures Wallet سے وائیدراول کی کوشش — ممکن نہیں؛ پہلے Transfer کریں۔
  4. ❌ Address کاپی کے بعد چیک نہ کرنا — کلپ بورڈ مالویئر ایڈریس بدل دیتا ہے (Address Swapping)۔
  5. ❌ پہلی وائیدراول بڑی رقم میں — پہلے چھوٹی ٹیسٹ وائیدراول کریں۔
  6. ❌ P2P ادائیگی Escro سے باہر — صرف بائننس کے P2P اسکرین سے کریں۔
  7. ❌ Whitelist بند رکھنا — اضافی تحفظ دستیاب ہے مگر استعمال نہیں ہو رہا۔

✅ خلاصہ

  • Spot Wallet = اصل اثاثے، ڈیپازٹ/وائیدراول کا مرکز۔
  • Futures Wallet = صرف ڈیریویٹوز؛ وائیدراول کے لیے Spot میں لائیں۔
  • ڈیپازٹ/وائیدراول میں Network + Address + Memo تینوں چیک کریں۔
  • Address Whitelist آن کریں؛ پہلی بار ٹیسٹ رقم بھیجیں۔
  • Available اور In Order کا فرق سمجھیں۔

📝 عملی مشق

  1. موبائل پر Wallet → Overview کھول کر کل تخمینہ اور ہر کوائن کی Available مقدار نوٹ کریں۔
  2. Spot سے Futures میں $5 کا فرضی Transfer کریں اور واپس لائیں۔
  3. ڈیپازٹ اسکرین کھولیں اور دیکھیں USDT کے کتنے نیٹ ورک دستیاب ہیں۔
  4. Address Whitelist آن کریں (Security سیٹنگز میں)۔
  5. اسکرین کے ساتھ لکھیں: وائیدراول سے پہلے کی تین جانچ۔

🧠 یاد رکھیں

"Spot = اصل مال، Futures = ٹریڈ کا ایندھن، Transfer = دونوں کے درمیان پل۔"

اصول: (1) نیٹ ورک/ایڈریس/Memo تین چیک، (2) Whitelist آن، (3) پہلے چھوٹی، پھر بڑی رقم۔
