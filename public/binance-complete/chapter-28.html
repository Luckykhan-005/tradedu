باب 28: بیک اپ اور ریکوری — اکاؤنٹ واپس پانا

بیک اپ = ایسی معلومات جو آپ کے فون، ای میل یا رسائی (access) ختم ہو جانے پر بھی آپ کو اپنا اکاؤنٹ واپس لانے دیتی ہیں۔ بائننس ایک custodial (امانت دار) ایکسچینج ہے — آپ کو seed phrase یا private key کی ضرورت نہیں، مگر 2FA ریکوری کوڈ اور تصدیق شدہ رابطوں کا بیک اپ لازم ہے۔

🎯 اس باب میں آپ سیکھیں گے

  • بائننس کا بیک اپ بمقابلہ والٹ کا seed phrase
  • 2FA ریکوری کوڈ — سب سے اہم بیک اپ
  • ای میل اور فون نمبر کی تبدیلی
  • Passkey / سیکیورٹی کلید کا بیک اپ
  • کھوئے ہوئے 2FA کا حل
  • بحالی (Account Recovery) کا عمل
  • بیک اپ کے عام نقصانات

📖 28.1 بائننس بمقابلہ بیرونی والٹ — اہم فرق

پہلوبائننس (Custodial)بیرونی والٹ (Self-Custody)
seed phrase❌ نہیں✅ 12/24 الفاظ لازمی
private key❌ نہیں✅ آپ کے پاس
بیک اپ کیا ہے2FA ریکوری کوڈ، ای میل، فونseed phrase / private key
رسائی کھو جائے توبائننس Support + تصدیقseed phrase کے بغیر مستقل نقصان

🔴 سب سے عام غلط فہمی: بہت سے لوگ سمجھتے ہیں کہ بائننس بھی ایک "seed phrase" دیتا ہے۔ نہیں — بائننس custodial ہے۔ جب کوئی آپ سے "بائننس کا seed phrase" مانگے تو وہ لازماً دھوکے باز ہے۔

📖 28.2 2FA ریکوری کوڈ — سب سے اہم بیک اپ

recall: 2FA سیٹ کرتے وقت بائننس کچھ Recovery Codes دیتا ہے۔ یہ کوڈ فون کے بغیر لاگ اِن کرنے کا واحد راستہ ہیں۔

Security → 2FA → Backup Codes / Recovery Codes
→ محفوظ جگہ پر کاپی کریں (کاغذ + پیپر والٹ)
→ ہر کوڈ صرف ایک بار استعمال ہوتا ہے

محفوظ کرنے کا طریقہ

✔ درست✘ غلط
کاغذ پر لکھ کر محفوظ جگہفون میں screenshot
الگ محفوظ مقام (ایل ایس پی سے دور)ای میل inbox میں
دو کاپیاں، دو مختلف مقاماتکلاؤڈ نوٹ/ چیٹ میں

⚠️ کوڈ کسی کے ساتھ شیئر نہ کریں — یہ 2FA کا متبادل دروازہ ہے۔

📖 28.3 ای میل اور فون نمبر کی تبدیلی

Profile → Security / Settings → Email / Phone → Change
→ پرانے + نئے ذرائع سے تصدیق → تبدیلی

💡 سب سے پہلے ای میل اور فون کو محفوظ بنائیں۔ اگر آپ کا ای میل ہی ہیکر کے پاس ہو جائے تو باقی سب بیکار ہے۔ بائننس کے لاگ اِن کی تصدیق اسی ای میل پر آتی ہے۔

  • اگر ای میل/فون پہلے سے ہی آپ کے پاس نہیں → Support کے ذریعے جانیں، ID/تصدیق کے ساتھ
  • تبدیلی کے بعد ردعمل کے لیے اپنی تصدیق شدہ ڈیوائس پر نظر رکھیں

📖 28.4 Passkey اور سیکیورٹی کلید

طریقہبیک اپ
Passkey (بائیو میٹرک/ڈیوائس)ہر ڈیوائس پر الگ؛ Google/Apple اکاؤنٹ سے سنکرون
Hardware Key (YubiKey)بنیادی کلید کے علاوہ ایک بیک اپ کلید رکھیں
Authenticator AppRecovery Codes + دوسرے فون / ایپ ایکسپورٹ

✅ دو آزاد راستے ہمیشہ رکھیں — ورنہ ایک ڈیوائس خراب ہونے پر آپ باہر رہ سکتے ہیں۔

📖 28.5 کھوئے ہوئے 2FA کا حل

1. لاگ اِن صفحے پر جائیں → "2FA accessible نہیں" منتخب کریں
2. Recovery Code درج کریں (اگر محفوظ ہے)
3. ورنہ Support کے ذریعے بحالی کی درخواست کریں
4. ID/دستاویز سے تصدیق کریں
5. بحالی کے بعد نیا 2FA سیٹ کریں + نیا backup لے لیں

⚠️ بحالی میں کئی دن لگ سکتے ہیں۔ اسی لیے بیک اپ پہلے سے رکھنا اتنا اہم ہے — بعد میں "پچھتاوا" کام نہیں آتا۔

⚠️ عام غلطیاں

  1. ❌ Recovery Codes نہ سنبھالنا — 2FA کھونے پر پھنس جانا
  2. ❌ کوڈز کی screenshot لینا یا ای میل inbox میں رکھنا
  3. ❌ ای میل کو غیر محفوظ رکھنا — ہیکر پہلے ای میل ہی لیتا ہے
  4. ❌ بائننس کا "seed phrase" کسی سے مانگنا/لینا — یہ وجود ہی نہیں رکھتا
  5. ❌ کسی کو Recovery Code یا OTP بتانا
  6. ❌ صرف ایک 2FA طریقے پر انحصار
  7. ❌ کسی "ریکوری ایجنٹ" کو پیسے دینا — دھوکا
  8. ❌ پرانا نمبر/ای میل اپ ڈیٹ نہ کرنا
  9. ❌ بحالی کے دوران جعلی لنک پر کلک کرنا
  10. ❌ بیک اپ ایک ہی جگہ رکھنا — ایک آگ سے سب ختم

✅ خلاصہ

  • بائننس custodial ہے — seed phrase نہیں، Recovery Codes بیک اپ ہیں
  • Recovery Code کاغذ پر، دو مختلف مقامات پر
  • ای میل اور فون سب سے پہلے محفوظ کریں
  • دو آزاد 2FA راستے رکھیں
  • 2FA کھو جائے تو Recovery → Support → تصدیق
  • "بائننس seed phrase" کہنے والا = دھوکے باز

📝 عملی مشق

  1. اپنے Recovery Codes تلاش کریں (نہ ہوں تو فوراً بنائیں)۔
  2. اُنہیں کاغذ پر لکھ کر محفوظ جگہ رکھیں۔
  3. چیک کریں: آپ کی ای میل اور فون نمبر درست اور قابلِ رسائی ہیں؟
  4. اپنے لیے بیک اپ چیک لسٹ بنائیں: 2FA، Recovery Codes، ایمیل، فون، Anti-Phishing۔
  5. ایک نوٹ لکھیں: "اگر میرا فون کل گم ہو جائے تو میرا اولین قدم ______ ہوگا"
  6. یادداشت بنائیں: "Recovery Code = ______ کی برابر چابی"

🧠 یاد رکھیں

بیک اپ وہ چھتری ہے جو دھوپ میں خریدتے ہیں، بارش میں نہیں۔ جب فون چوری ہو جائے یا ای میل بند ہو جائے، تب بیک اپ بنانے کا وقت نہیں ہوتا۔

آج، اسی وقت، ایک کاغذ پر اپنے Recovery Codes لکھ کر ایسی جگہ رکھیں جہاں صرف آپ پہنچ سکیں۔ یاد رکھیں: "بائننس میں seed phrase نہیں ہوتا — اسی لیے Recovery Codes ہی آپ کا اصل بیک اپ ہیں۔"
