سبق 8: رسک ماڈل

ٹریڈنگ کا اصل راز کمانا نہیں، بلکہ زندہ رہنا ہے۔ جب تک آپ زندہ رہتے ہیں، آپ کو کمانے کے نئے موقعے ملتے رہتے ہیں۔ لیکن ایک ہی بڑا نقصان آپ کو مارکیٹ سے باہر نکال سکتا ہے۔ اسی لیے رسک ماڈل آپ کے پورے پلان کا سب سے اہم حصہ ہے — یہ وہ چیز ہے جو آپ کو ہر ٹریڈ میں کتنا خطرہ اٹھانا ہے، یہ طے کرتی ہے۔ رسک ماڈل کے بغیر کوئی بھی شخص طویل عرصے تک کامیاب نہیں رہ سکتا۔

رسک ماڈل کا بنیادی اصول یہ ہے کہ آپ ہر ٹریڈ میں اپنے اکاؤنٹ کا ایک مقررہ اور چھوٹا سا حصہ ہی خطرے میں ڈالیں۔ پیشہ ور تاجروں کا سب سے عام اصول ہے کہ ہر ٹریڈ میں اکاؤنٹ کا صرف 1% سے 2% خطرے میں ڈالیں۔ یعنی اگر آپ کا اکاؤنٹ 100,000 روپے ہے، تو آپ ہر ٹریڈ میں صرف 1,000 سے 2,000 روپے ہی خطرے میں ڈالیں گے۔ یہی اصول آپ کو اُس وقت جمله دیتا ہے جب مارکیٹ آپ کے خلاف ہو۔

بنیادی اصول: ہر ٹریڈ میں 1-2% سے زیادہ رسک نہ لیں۔ یہ چھوٹا سا اصول آپ کی طویل کامیابی کی بنیاد ہے۔

رسک اور گراوٹ (ڈرا ڈاؤن) کا آپس میں گہرا تعلق ہے۔ فرض کریں آپ ہر ٹریڈ میں 2% رسک لیتے ہیں۔ اگر آپ مسلسل پانچ ٹریڈز ہارتے ہیں تو آپ کا اکاؤنٹ تقریباً 10% نیچے آ جاتا ہے، لیکن آپ اسے جلد واپس حاصل کر سکتے ہیں۔ لیکن اگر آپ ہر ٹریڈ میں 20% رسک لیتے ہیں، تو صرف پانچ ہارنے والی ٹریڈز آپ کی اکثر سرمایہ ختم کر دیں گی۔ بڑا رسک چھوٹے نقصانات کو بھی مہلک بنا دیتا ہے، جبکہ چھوٹا رسک بڑے نقصانوں کو بھی قابلِ برداشت بنا دیتا ہے۔

رسک ماڈل میں آپ کی ذاتی رسک برداشت کی صلاحیت بھی شامل ہے۔ رسک برداشت کا مطلب ہے کہ آپ کتنا نقصان برداشت کر سکتے ہیں، نہ کہ مالی طور پر بلکہ نفسیاتی طور پر بھی۔ اگر آپ جانتے ہیں کہ آپ کو کسی بھی قیمت پر اپنی اصلی سرمایہ کو حفاظت کرنی ہے، تو آپ چھوٹا رسک لیں گے۔ ایک بہترین اصول یہ ہے کہ آپ ہمیشہ اُسی رسک سے کم لیں جو آپ کھونے کی استطاعت رکھتے ہیں — یعنی وہ رقم، کھونے کے بعد بھی آپ کی زندگی معمول پر رہے۔

ایک اور وجہ ہے کہ چھوٹا رسک کیوں بہتر ہے: موقعوں کی لامحدود زنجیر۔ ٹریڈنگ میں ایک چھوٹے نقصان کے بعد آپ کو بہت سے نئے موقعے ملتے ہیں۔ لیکن اگر آپ نے اپنا آدھا اکاؤنٹ ایک ٹریڈ میں گنوا دیا ہے، تو آگے کھیلنے کا کوئی موقع ہی نہیں۔ چھوٹا رسک اس بات کو یقینی بناتا ہے کہ آپ ہار کے بعد بھی میدان میں رہیں، اور جب موقع آئے تو آپ اُسے لے سکیں۔

یوٹا: رسک ماڈل آپ کا محافظ ہے۔ اس کا مقصد پورے اکاؤنٹ کو ختم ہونے سے بچانا ہے۔ جب آپ چھوٹا رسک لیتے ہیں تو آپ کی ٹریڈنگ بھی پرسکون ہو جاتی ہے۔ آپ حقیقت میں جانتے ہیں کہ کوئی بھی ٹریڈ آپ کو تباہ نہیں کر سکتی۔ اگلے سبق میں ہم رسک کو سائز (پوزیشن سائزنگ) کے طور پر استعمال کرنا سیکھیں گے۔

اہم نکات

۱۔ ہر ٹریڈ میں 1-2% سے زیادہ رسک نہ لیں۔

۲۔ چھوٹا رسک بڑے نقصان کو بھی قابلِ برداشت بنا دیتا ہے۔

۳۔ اپنی رسک برداشت کی صلاحیت کو جانیں۔

۴۔ کبھی بھی اُس رقم کا خطرہ نہ لیں جو آپ کھونے کے متحمل نہ ہوں۔

ہوم ورک

۱۔ اپنے پلان کے لیے ہر ٹریڈ کا فکس رسک (1-2%) طے کریں۔

۲۔ اپنی رسک برداشت کی حد لکھیں۔

۳۔ اپنے موجودہ اکاؤنٹ کا 1% رسک کا حساب لگائیں۔
