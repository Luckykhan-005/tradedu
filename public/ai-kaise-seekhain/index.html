AI ki asaan tareef

Artificial Intelligence (AI) computer ko aisa banane ka naam hai jo woh kaam kar sake jin ke liye aam tor par insani zehanat chahiye hoti hai: dekhna, sunna, samajhna, faisla karna aur seekhna. Computer ko har qadam likh kar dene ke bajaye hum usay data dete hain aur woh khud pattern seekhta hai.

Example: Aap ke Gmail ka spam filter. Kisi ne yeh rules nahi likhe ke "lottery" likha ho to spam hai. Filter ne lakhon emails dekh kar khud seekha ke spam kaisa dikhta hai. Isi tarah Google Maps traffic ka andaza lagata hai aur phone ka face unlock aap ka chehra pehchanta hai.

Python hi kyun?

AI ki lagbhag saari libraries (NumPy, Pandas, PyTorch, scikit-learn) Python mein hain. Is ki zubaan angrezi jaisi saaf hai, is liye beginners ke liye behtareen hai. Install ki fikar chorein: Google Colab browser mein chalta hai aur bilkul free hai.

Pehla program

naam = "Ali"
marks = [70, 85, 90]
average = sum(marks) / len(marks)
print(naam, "ka average:", average)

Yahan naam aik variable hai (text), marks aik list hai (kai values), aur sum, len Python ke apne functions hain. Natija: Ali ka average: 81.67 ke qareeb.

Faisla aur dohrana

def grade(avg):
    if avg >= 80:
        return "A"
    return "B"

for m in marks:
    print(m, "marks")
print("Grade:", grade(average))
Example: def aik "recipe" hai jo baar baar istemal ho sakti hai. for list ki har cheez par wohi kaam dohrata hai. AI mein hazaron data rows par yehi kaam hota hai.

Is chapter ke baad aap:

Ghabrayen nahi. Practical AI ke liye 4 cheezain chahiye, aur woh bhi sirf us had tak jitni zaroorat hai.

1. Linear Algebra: data ko numbers ki list banana

Computer ko sab kuch numbers mein chahiye. Aik vector numbers ki list hai, aur matrix unki table.

Example: Aik ghar = [1200 sq ft, 3 kamray, 5 saal purana]. Yeh aik vector hai. 1000 gharon ki table aik matrix hai. Model in numbers ko wazan (weights) se multiply kar ke qeemat nikalta hai.
import numpy as np
ghar = np.array([1200, 3, 5])
wazan = np.array([0.02, 1.5, -0.3])
print(ghar @ wazan)   # 27.0

2. Probability: yaqeen ka andaza

Probability 0 se 1 ke darmiyan hoti hai. 0.9 ka matlab "90% imkan". Model aksar jawab ke sath yeh bhi batata hai: "yeh email 95% spam hai."

3. Statistics: data ko samajhna

  • Mean: average. Median: bichli value (bohat bari values se kam mutasir hoti hai).
  • Standard deviation: data kitna phailaa hua hai.
Example: 5 logon ki tankhwah 40k, 45k, 50k, 55k, 1 million. Mean bohat zyada nazar aaye ga, median 50k hai aur asal haal batata hai.

4. Calculus: seekhna kaise hota hai

Model ki ghalti (loss) ko kam karna hi seekhna hai. Gradient bata'ta hai ke ghalti kis taraf kam hogi, bilkul pahaar se neeche utarne ki tarah. Is tareeqay ko Gradient Descent kehte hain.

Zaroori baat: Aaj ki libraries calculus khud karti hain. Aap ko sirf concept samajhna hai, formula yaad nahi karna.

Gradient Descent aankhon se dekhein (numbers ke sath)

Maan lein ghalti ka formula loss = (w - 3)² hai. Is ka sab se kam point w = 3 par hai, lekin model ko yeh pata nahi. Woh 0 se shuru karta hai aur slope (gradient) dekh kar qadam leta hai. Slope ka formula 2 × (w - 3) hai, aur learning rate = 0.1 (qadam ka size).

Dekhein: w har qadam par 3 ke qareeb ja raha hai, aur jaise jaise qareeb aata hai slope chhota hota jata hai, is liye qadam bhi chhotay hotay jatay hain. Yehi neural network ki training hai, bas w ki jagah lakhon weights hotay hain.

Learning rate ka asar: bohat chhota ho to model bohat dheere seekhta hai. Bohat bara ho (maslan 1.1) to w 0 se seedha 6.6 par kood jata hai, minimum ke upar se guzar jata hai aur ghalti barhti hai. Is liye learning rate model ki sab se ahem settings mein se hai.

Matrix aur vector: kai gharon ka score aik sath

Pehlay hum aik ghar ka score nikal rahe thay. Matrix mein har row aik ghar hai, aur multiply karne se sab gharon ke score aik hi baar mein mil jatay hain.

import numpy as np
X = np.array([[1000, 2, 10],     # ghar 1
              [1500, 3, 2]])     # ghar 2
wazan = np.array([0.02, 1.5, -0.3])
print(X @ wazan)                 # [20.  33.9]

Ghar 2 ka hisaab: 1500×0.02 + 3×1.5 + 2×(-0.3) = 30 + 4.5 - 0.6 = 33.9. Neural network ki har layer asal mein yehi matrix multiplication hai.

Probability aur Bayes: ek asaan example

Maan lein 20% emails spam hain. "lottery" lafz 90% spam mein aata hai aur sirf 5% aam emails mein. Agar kisi email mein "lottery" ho to spam hone ka imkan kitna hai?

Hisaab:
Spam aur "lottery": 0.20 × 0.90 = 0.18
Aam aur "lottery": 0.80 × 0.05 = 0.04
Imkan = 0.18 / (0.18 + 0.04) = 0.82, yaani taqreeban 82%.
Sirf aik lafz ne 20% ke andaze ko 82% bana diya. Spam filter aise bohat se saboot jama kar ke faisla karta hai.

Standard deviation: data kitna phailaa hua hai

Do classes ke average marks 80 hain. Class A: 70, 80, 90. Class B: 79, 80, 81. Average wohi hai, lekin A mein farq zyada hai.

  • Class A: average se farq -10, 0, +10. Un ke squares 100, 0, 100. Un ka average 66.7. Jad (square root) taqreeban 8.2.
  • Class B: farq -1, 0, +1. Squares 1, 0, 1. Average 0.67. Jad taqreeban 0.8.

Chhota standard deviation matlab data average ke qareeb jama hai, bara matlab phailaa hua. ML mein isi se pata chalta hai ke features ka scale kitna mukhtalif hai (Chapter 10).

Har algorithm gehrai se

1. Linear Regression. Data mein aisi seedhi lakeer dhoondta hai jo points ke sab se qareeb ho: qeemat = w × area + b. Chapter mein diye gaye data (800→40, 1000→50, 1200→60, 1500→75) mein w = 0.05 (har sq ft par 0.05 lakh) aur b = 0 nikalta hai. Model ki ghalti ko MSE (Mean Squared Error) se napte hain: har jawab ki ghalti ka square le kar average. Training ka maqsad MSE kam karna hai.

2. Logistic Regression. Naam mein regression hai lekin yeh classification karta hai. Yeh aik number nikalta hai aur usay sigmoid function se 0 aur 1 ke darmiyan imkan (probability) mein badal deta hai. Agar imkan 0.5 se zyada ho to "haan", warna "nahi".

from sklearn.linear_model import LogisticRegression

m = LogisticRegression().fit(X, y)
print(m.predict_proba([[5]]))            # [[fail ka imkan, pass ka imkan]]

3. Decision Tree. Sawalon ka darakht: har qadam par woh sawal poochta hai jo data ko sab se saaf do hisson mein baante. Masla: agar darakht bohat gehra ho jaye to data ratt leta hai (overfitting). Hal: gehrai hadd mein rakhein.

from sklearn.tree import DecisionTreeClassifier

4. Random Forest. Aik darakht ki jagah bohat se (maslan 100) alag trees banata hai, har aik data ke thore alag hisse par, aur sab ki raye (voting) se faisla karta hai. Misal: 100 doctors ki raye aik doctor se zyada bharose ki hoti hai. Isi liye yeh aksar pehli pasand hai.

from sklearn.ensemble import RandomForestClassifier

print(clf.score(X_te, y_te))      # test par accuracy

5. KNN (K-Nearest Neighbors). Naye point ke K sab se qareebi saathiyon ko dekhta hai aur unki aksariyat ki raye leta hai. Agar K=3 aur 3 mein se 2 qareebi ghar mehnge hain, to naya ghar bhi mehnga mana jata hai. Dhyan: KNN doori napta hai, is liye features ko aik scale par laana zaroori hai (Chapter 10).

6. K-Means. Bina label ke groups banata hai:

  1. K markaz (center) randomly chunta hai.
  2. Har point ko sab se qareebi markaz ka member bana deta hai.
  3. Har group ka naya markaz us ke members ka average bana deta hai.
  4. Qadam 2 aur 3 tab tak dohrata hai jab tak groups na badlein.

7. PCA. Kai features ko kam features mein is tarah compress karta hai ke zyada tar maloomat bach jaye. Misal: aik bari tasveer ko chhota kar dena lekin shakl samajh aati rahe. Visualization aur sust models ko tez karne mein kaam aata hai.

Chapter 9: Model Evaluation

Is chapter ke baad aap: overfitting pehchan sakein ge aur accuracy, precision, recall nikal sakein ge.

Train/Test split

Model ko jis data par seekhaya, usi par jaanchna aisa hai jaise imtihan ka paper pehlay hi bata dena. Is liye data ko do hissay karte hain: Train (seekhne ke liye, aam tor par 80%) aur Test (jaanchne ke liye, 20%).

Overfitting aur Underfitting

  • Underfitting: model bohat saada, train aur test dono par kharab.
  • Overfitting: model ne data ratt liya, train par bohat achha lekin test par kharab.

Classification ke metrics

MetricFormulaIs example mein
Accuracy(TP+TN) / total85 / 100 = 85%
PrecisionTP / (TP+FP)40 / 50 = 80%
RecallTP / (TP+FN)40 / 45 = 89%
F1Precision aur Recall ka balancekareeban 84%
Accuracy dhoka de sakti hai: agar 99% emails spam nahi hain, to "sab ko not spam" kehne wala model bhi 99% accurate hai magar bekaar. Aisay mein Precision/Recall dekhein.

Precision aur Recall: kab kaun ahem?

  • Precision: model ne jinhein "haan" kaha, un mein se kitne sach mein "haan" thay? Spam filter mein yeh ahem hai: aap ki zaroori email spam mein nahi jani chahiye.
  • Recall: jitne asal "haan" thay, un mein se kitne model ne pakray? Bimari ki screening mein yeh ahem hai: koi mareez chhootna nahi chahiye, chahe kuch ghalat alarm ho.

Dono mein tawazun hota hai: model ko zyada sakht karein to precision barhti hai magar recall girti hai, aur ulta. F1 dono ka balance hai. Is example mein: F1 = 2 × 0.80 × 0.889 / (0.80 + 0.889) ≈ 0.84.

Number batane wale models (regression) ke metrics

Asal qeematein 50, 60, 70 aur model ke andaze 52, 58, 75 hon to ghaltiyan 2, 2, 5 hain.

MAE samajhna asaan hai: "average andaza 3 lakh ghalat hai". Agar aik bhi bohat bari ghalti nuqsan deh ho to RMSE dekhein.

Cross-validation: sirf aik split par bharosa na karein

Aik hi train/test split ittifaq se achha ya bura ho sakta hai. 5-fold cross-validation mein data ko 5 hisson mein baantte hain. Har baar aik hissa test hota hai aur baaqi 4 train, yoon 5 nateejay milte hain, aur unka average aap ka asal andaza hota hai.

from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X, y, cv=5)
print(scores, scores.mean())

Overfitting se bachne ke tareeqay

  • Zyada data jama karna.
  • Model ko saada rakhna (maslan tree ki gehrai kam karna).
  • Regularization (weights ko bohat bara hone se rokna).
  • Cross-validation se jaanchna.
  • Zaroori na features hata dena.
Data leakage (khufiya chori): agar test data ki maloomat kisi na kisi tareeqay se training mein aa jaye to nateeja jhoota achha aata hai. Maslan scaling ya khali values bharne ke liye poore data ka average istemal karna. Hamesha pehlay train/test split karein, phir sirf train se seekh kar dono par lagayen.

Data: 50, 52, 53, 55, 500. IQR tareeqa: Q1 (25%) = 52, Q3 (75%) = 55, farq IQR = 3. Upar ki had = Q3 + 1.5 × IQR = 59.5. Is se bari har value outlier hai, yahan 500.

Scaling kyun aur kaise?

Area 1000 ke qareeb hai aur kamray 3 ke qareeb. Bina scaling ke KNN aur Gradient Descent wale models bare numbers ko zyada ahmiyat de dete hain. StandardScaler har value ko (x - average) / standard deviation mein badalta hai. Misal: marks 70, 80, 90 (average 80, SD 8.2) ban jatay hain ≈ -1.2, 0, +1.2.

  • StandardScaler: average 0 aur SD 1 (aam pasand).
  • MinMaxScaler: sab values 0 se 1 ke darmiyan.
Yaad rakhein: scaler ko fit sirf train data par karein, phir transform train aur test dono par (Chapter 9 ka data leakage). Decision Tree aur Random Forest ko scaling ki zaroorat aksar nahi hoti.

Encoding ki do qismein

  • Ordinal / Label: jab tarteeb ho (chhota=0, darmiyana=1, bara=2).

  • price_per_ft = price / area (qeemat per sq ft).
  • Do columns ka jor ya farq (maslan kul kamray = bedrooms + bathrooms).

Data cleaning ki checklist

  1. df.info() aur df.describe() se data ko samjhein.
  2. Dohrayi hui rows hatayen (drop_duplicates).
  3. Khali values ka faisla karein.
  4. Outliers dekhein.

  6. Train/test split karein.
  7. Phir scaling (sirf train se seekh kar).

Chapter 12: Neural Networks

Is chapter ke baad aap: neuron, layers, activation function aur backpropagation ka asaan matlab samjh lein ge.

Neural Network insani dimagh se mutasir aik structure hai: bohat se chhote "neurons" jo aik doosray se jure hotay hain. Har neuron aik chhota sa hisaab karta hai, aur jab hazaron milte hain to woh pechida pattern pakar lete hain.

Aik neuron kya karta hai?

Wohi jo Chapter 5 mein dekha: inputs ko wazan (weights) se multiply karna, jama karna, aur phir aik activation function se guzarna. Activation function network ko seedhi lakeer se aagay pechida shaklein seekhne ke qabil banata hai (maslan ReLU manfi numbers ko 0 kar deta hai).

Network seekhta kaise hai?

  • Forward pass: input se output tak andaza.
  • Loss: andaze aur asal jawab ka farq.
  • Backpropagation: ghalti ko peechay ki taraf bhej kar batana ke har weight ne kitni ghalti ki.
  • Gradient Descent: weights ko thora sa theek karna. Yeh poora chakkar hazaron baar dohrata hai.
Example: Ghar ki qeemat wala network. Input: area, kamray, umar. Pehle andaza 20 lakh nikla, asal 25 lakh. Ghalti 5 lakh. Backpropagation bata'ti hai ke area ka weight thora barhao, umar ka weight thora ghatao, aur agli baar andaza behtar hota hai.

Aik neuron ka hisaab (numbers ke sath)

Maan lein aik neuron ke inputs x = [2, 3], weights w = [0.5, -1] aur bias b = 1 hain. Bias aik extra number hai jo neuron ko shift karne deta hai.

z = 2×0.5 + 3×(-1) + 1 = 1 - 3 + 1 = -1
ReLU lagane par: max(0, -1) = 0, yaani neuron "khamosh" raha.
Agar input [4, 1] hota: z = 2 - 1 + 1 = 2, ReLU ke baad 2, neuron "active" hua.

Activation functions ki qismein

SigmoidHar number ko 0 se 1 ke darmiyan karta haiHaan/Nahi wala output
SoftmaxKai numbers ko is tarah badalta hai ke jama 1 ho (imkan)Kai categories ka output (0 se 9 ke digits)

Hidden layers kyun? Digit pehchanne ki misal

Aik 28×28 tasveer 784 numbers hoti hai. Network ki pehli hidden layer chhoti lakeerein aur kinare pakarti hai, agli layer unhein jor kar goley (loops) aur seedhi lakeerein banati hai, aur aakhri layer inse digit pehchanti hai ("goley aur seedhi lakeer = 9"). Yani har layer pichli layer se bara concept banati hai. Isi liye "deep" (gehra) learning kehte hain.

Network ke parameters gino

Chapter mein bane network (3 input, 4 hidden, 2 output) mein: 3×4 + 4×2 = 20 weights aur 4 + 2 = 6 biases, kul 26 parameters. Aaj ke bare LLMs mein yeh tadad arbon tak hoti hai, aur training mein sab ko theek karna parta hai.

Training ki zaroori istilahat

  • Epoch: poore training data par aik mukammal guzar.
  • Batch: data ka chhota hissa jis par aik baar weights theek hotay hain. 1000 samples aur batch size 100 ho to aik epoch mein 10 updates hotay hain.
  • Learning rate: qadam ka size (Chapter 5).

Neural network ka overfitting

Bare networks data ratt lene mein bohat maahir hotay hain. Dropout training ke dauran kuch neurons ko randomly band kar deta hai taake network kisi aik raste par nirbhar na ho. Early stopping tab training rok deti hai jab validation ghalti barhne lage.

Chapter 14: CNN, Computer Vision

Is chapter ke baad aap: samjh jayen ge ke AI tasveer kaise "dekhta" hai.

Tasveer pixels (numbers) ki table hoti hai. CNN (Convolutional Neural Network) chhote chhote filters ko poori tasveer par sarka kar patterns dhoondta hai: pehlay kinare aur lakeerein, phir aankh aur naak, aakhir mein poora chehra.

  • Convolution: filter se patterns (kinare, shakl) nikalna.
  • Pooling: tasveer chhoti kar ke sirf ahem cheez rakhna.
  • Flatten + Dense: aakhir mein faisla karna ke yeh kya hai.
Example: Phone ka face unlock, hospital mein X-ray se bimari ki nishandehi, kisan ke khet ki tasveer se fasal ki bimari pehchanna, aur gaari mein lane detection. Sab CNN ya us ke jadeed rishtedaron par chalte hain.

Aam tasks

TaskKaam
ClassificationTasveer mein kya hai? (billi ya kutta)
Object DetectionKya hai aur kahan hai? (box ke sath)
SegmentationHar pixel kis cheez ka hai

Tasveer computer ke liye kya hai?

  • Grayscale tasveer: numbers ki aik table, har pixel 0 (kala) se 255 (safaid). 28×28 ki tasveer = 784 numbers.
  • Rangeen tasveer: 3 tables (Red, Green, Blue), yaani shape (height, width, 3).

Convolution aik chhoti misal se

Filter aik chhoti 3×3 table hai jo tasveer ke upar sarakti hai. Har jagah woh milte hue numbers ko multiply kar ke jama karta hai. Yeh filter upar se neeche brightness ka farq (horizontal kinara) pakarta hai:

Filter:  [ 1  1  1]       Patch A (kinara):  [9 9 9]
         [ 0  0  0]                          [5 5 5]
         [-1 -1 -1]                          [1 1 1]

Patch A: (9+9+9)×1 + 0 + (1+1+1)×(-1) = 27 - 3 = 24   (bara number: kinara mila)
Patch B (sapaat, sab 5): 15 + 0 - 15 = 0              (kinara nahi)

CNN mein aise bohat se filters hotay hain aur woh khud seekhte hain ke kaun se patterns kaam ke hain. Pehle filters kinare pakarte hain, aagay wale shaklein aur cheezein.

Pooling aur stride

Max pooling (2×2): har 2×2 hissay se sab se bari value rakhta hai. [[1, 3], [2, 4]] se 4 bachta hai. Is se tasveer chhoti hoti hai magar sab se ahem cheez bachi rehti hai. Stride filter ke sarakne ka qadam hai (stride 2 matlab 2 pixel ka qadam, is se output chhota hota hai).

Seedha Dense network tasveer ke liye kyun nahi?

28×28 ki chhoti tasveer ke liye bhi Dense layer ko har pixel se har neuron ka alag weight chahiye, bohat zyada parameters. Aur agar digit thora sa kisi aur jagah ho to naya masla. CNN mein aik hi filter poori tasveer par istemal hota hai, is liye parameters kam hotay hain aur cheez kahin bhi ho pehchani jati hai.

Data augmentation: zyada tasveerein banana

Agar tasveerein kam hon to unhein ulta karke, thora ghuma kar ya zoom kar ke nayi misalein banayi jati hain. Model ko ek cheez alag alag shakl mein dekhne ka mauqa milta hai aur overfitting kam hoti hai.

Transfer learning: bana banaya model istemal karein

Chhoti dataset ho to model shuru se train karna zaroori nahi. Pehle se lakhon tasveeron par train hua model (jaise MobileNet) le kar sirf aakhri hissa apne kaam ke liye train karein.

        keras.layers.GlobalAveragePooling2D(),
        keras.layers.Dense(2, activation="softmax")])   # apni 2 categories

Chapter 15: RNN/LSTM aur Sequence Data

Is chapter ke baad aap: sequence data ki pehchan kar sakein ge aur jaan lein ge ke RNN/LSTM aaj kahan khare hain.

Kuch data mein tarteeb ahem hoti hai: jumla, stock ki qeemat, awaaz, mausam. "Ali ne Ahmed ko maara" aur "Ahmed ne Ali ko maara" ke alfaz wohi hain magar matlab ulta.

  • RNN: sequence ko aik aik cheez kar ke parhta hai. Masla: lambay jumlon mein shuru ki baat bhool jata hai.
  • LSTM: RNN ka behtar rup jis mein "gates" hotay hain jo tay karte hain kya yaad rakhna hai aur kya bhoolna hai.
Aaj ki haqeeqat: text ke zyada tar kaam ab Transformers (Chapter 17) karte hain, kyun ke woh poora jumla aik sath dekhte hain. RNN/LSTM phir bhi chhoti time-series aur sensor data mein kaam aate hain, aur concept samajhna Transformers ke liye bhi madadgar hai.
Example: Aap ka keyboard agla lafz suggest karta hai, ya aap ke dukan ki pichli 30 din ki sales se agle hafte ka andaza.

RNN qadam ba qadam

RNN har qadam par do cheezein leta hai: naya input aur pichli yaaddasht (hidden state). In se naya hidden state banata hai, jo agle qadam ko jata hai. Jumla "Main kal Lahore gaya" ke liye: "Main" parha, yaaddasht banayi. "kal" aaya to "Main" ki yaaddasht ke sath mila kar nayi yaaddasht, aur isi tarah aage. Aakhir tak ki yaaddasht mein poore jumle ka khulasa hota hai.

RNN ki kamzori: yaaddasht phiki par jati hai

Kisi se kisi tak sargoshi karte hue 50 logon ki qatar sochein. Pehle shakhs ki baat aakhri tak pohanchte pohanchte bigar jati hai. Isi tarah lambay sequences mein RNN shuru ki baat bhool jata hai, kyun ke training mein gradient peechay jate hue bohat chhota ho jata hai (vanishing gradient).

LSTM ke teen "gates"

LSTM ko aik notebook samjhein jis mein woh tay karta hai kya likhna aur kya mitana hai:

  • Forget gate: purani yaaddasht mein se kya bhoolna hai?
  • Input gate: naye input mein se kya yaad rakhna hai?
  • Output gate: abhi ki yaaddasht mein se kya bahar dena hai?

Isi system se LSTM lambay sequences mein ahem baatein sambhal kar rakhta hai.

Is chapter ke baad aap: samjh jayen ge ke ChatGPT/Claude jaisay models andar se kaise kaam karte hain, aur token, attention, context window ka matlab jaan lein ge.

LLM (Large Language Model) asal mein aik bohat bara Transformer network hai jo aik hi kaam seekhta hai: agla token (lafz ka hissa) kya hoga? Bohat sa text parh kar yeh andaza itna behtar ho jata hai ke model jawab likhna, translate karna aur code likhna seekh leta hai.

Model text ko kaise dekhta hai?

  • Tokenization: text ko chhote tukron (tokens) mein torna.
  • Embedding: har token ko numbers ki list (vector, Chapter 5) bana dena jo us ka matlab pakarti hai.
  • Attention: har lafz dekhta hai ke jumle ke kaun se doosray lafz us ke liye ahem hain.
  • Output: agle token ki probability, phir aik chun kar dohrana.
Example: "woh" se murad billi hai, doodh nahi. Attention ki wajah se model yeh rishta pakar leta hai. Purane RNN lambay jumlon mein yeh bhool jatay thay.

Model kaise tayyar hota hai?

MarhalaKya hota hai
Pre-trainingBohat bare text par agla token seekhna
Instruction tuningSawal/jawab ki misalon se hukm manna seekhna
Preference trainingInsani feedback se behtar aur mehfooz jawab dena

Token: model ke liye text ki ikai

Model alfaz nahi, tokens dekhta hai. Aik token poora lafz, lafz ka hissa, ya sirf aik nishan ho sakta hai. Maslan "Machine learning" aam tor par 2 tokens mein toot jata hai. Angrezi ka aam lafz aksar aik token hota hai, jabke Roman Urdu aur Urdu aksar zyada tokens mein toot jate hain. Is liye wohi baat Urdu mein likhne par context window zyada istemal hoti hai aur API ka kharcha bhi zyada ho sakta hai.

Embedding: lafz ka matlab numbers mein

Har token ko numbers ki aik lambi list (vector) mil jati hai. Milte julte matlab wale lafzon ke vectors qareeb hotay hain ("ghar" aur "makan"), aur alag matlab walay door. Mashhoor misal: "badshah" − "mard" + "aurat" ≈ "malika". Matlab vectors mein rishte bhi chhupe hotay hain.

Attention gehrai se: Query, Key, Value

Kutub khane ki misal lein. Aap ka Query hai "mujhe kisi bimari ki kitab chahiye". Har kitab ke upar aik Key (label) hai, aur andar ka maazmoon Value. Aap apne query ko har label se milate hain (dot product, Chapter 5), jo zyada milta ho us ko zyada number milta hai. Phir softmax (Chapter 12) in numbers ko wazan banata hai jin ka jama 1 ho, aur aap sab kitabon ke maazmoon ko un wazan ke hisaab se mila lete hain.

Jumle "Billi ne doodh piya kyunke woh bhooki thi" mein "woh" apna query bana kar baaqi alfaz ki keys se milata hai, "Billi" ki key sab se zyada milti hai, isliye "woh" ka matlab billi se bhar jata hai. Transformer mein yeh kaam multi-head attention ke zariye kai alag nazariyon (heads) se hota hai, maslan aik head grammar dekhta hai aur doosra matlab.

Jawab kaise banta hai: ek ek token

Sawal "Pakistan ki rajdhani ___" par model har mumkin agle token ko imkan deta hai, maslan Islamabad 95%, Lahore 3%, Karachi 1%. Phir aik token chuna jata hai, jawab mein jur jata hai, aur poora jumla dobara model ko input ban kar jata hai. Yeh chakkar jawab khatam hone tak chalta hai.

Temperature chunao ko control karta hai: kam temperature par model sab se mumkin lafz chunta hai (mehfooz, mustaqil jawab), zyada temperature par kam imkan wale lafz bhi chun leta hai (zyada takhleeqi, magar ghalti ka khatra zyada).

Context window aur "bhool jana"

Model sirf utna dekh sakta hai jitna context window mein aaye. Bohat lambi guftagu mein shuru ki baatein bahar nikal sakti hain ya kam wazan paati hain. Isi liye lambi chat mein kabhi kabhi model purani baat bhool jata hai, aur zaroori baatein dobara likhna mufeed hota hai.

Hallucination kyun hoti hai?

Model ko "agla lafz kya hoga" sikhaya gaya hai, "sach kya hai" nahi. Jahan usay jawab nahi aata wahan bhi woh bahaa'o mein sahi lagne wala jawab bana deta hai. Is liye aham facts hamesha khud verify karein, ya RAG (Chapter 19) se model ko asal documents dein.

Zaroori hadood: model ka context window hota hai (aik waqt mein kitna text dekh sakta hai). Model aksar yaqeen se ghalat jawab bhi de deta hai (hallucination), kyun ke woh pattern se likhta hai, fact check nahi karta.

Chapter 19: RAG, apna data AI ko dena

Is chapter ke baad aap: RAG ka nakshah samjh kar chota retrieval system bana sakein ge.

Model ko aap ki company ki policy ya aap ki notes nahi pata, aur us ka ilm purana ho sakta hai. RAG (Retrieval-Augmented Generation) ka hal: pehlay aap ke documents mein se mutaliqa hissa dhoondein, phir wohi hissa sawal ke sath model ko dein.

Example: Aap ki company ka HR chatbot. Employee poochta hai "chhutti kaise lein?". System policy documents mein se sab se mutaliqa paragraph dhoondta hai aur model us ki bunyad par jawab deta hai, apni qayas-arai par nahi.

Retrieval ka chhota code

from sentence_transformers import SentenceTransformer
m = SentenceTransformer("all-MiniLM-L6-v2")
docs = ["Leave requests are submitted on the HR portal.",
        "Salary is paid on the 28th of every month."]
D = m.encode(docs, normalize_embeddings=True)
q = m.encode(["When do I get my salary?"], normalize_embeddings=True)
best = int((D @ q.T).argmax())
print(docs[best])      # salary wali line

Yeh model English text ke liye behtar hai. Roman Urdu ya Urdu documents ke liye multilingual embedding model (jaise paraphrase-multilingual-MiniLM-L12-v2) istemal karein.

Chunking: documents ko tukron mein kyun torein?

Poora 100 safhon ka document aik vector mein daalna theek nahi, kyun ke vector mein sab kuch ghul mil jata hai. Is liye documents ko chhote chunks (aam tor par 200 se 400 alfaz) mein torte hain. Chunks ke darmiyan overlap (maslan 50 alfaz) rakhte hain taake kisi jumle ke beech mein toot kar maani na bigar jaye.

  • Chunk bohat chhota: maani adhoore, jawab ke liye kaafi context nahi.
  • Chunk bohat bara: matlab ghul mil jata hai aur model ko faltu text milta hai.

Similarity kaise napte hain? Cosine similarity

Do vectors ka rukh (direction) kitna milta hai, yeh napne ke liye cosine similarity istemal hoti hai: 1 matlab bilkul milta hua, 0 matlab koi taluq nahi.

Vector A = [1, 2], B = [2, 4]: dot = 1×2 + 2×4 = 10, lambai √5 × √20 = 10, similarity = 1 (aik hi rukh).
Vector C = [2, -1]: dot = 1×2 + 2×(-1) = 0, similarity = 0 (koi taluq nahi).

Top-k retrieval aur prompt banana

scores = (D @ q.T).ravel()              # har chunk ka score
top = scores.argsort()[::-1][:3]        # sab se qareebi 3
ctx = "\n---\n".join(docs[i] for i in top)
prompt = f"Sirf is context se jawab do.\n\nContext:\n{ctx}\n\nSawal: {sawal}"

Sirf aik chunk ki jagah 3 chunks dene se jawab ke chhoot jane ka imkan kam hota hai. Jawab ke sath source (kaun sa document/safha) bhi dikhayen taake user khud check kar sake.

RAG ko jaanchna

20 se 30 asal sawal likhein jin ke jawab aap ko documents se maloom hon. Har sawal par do cheezein dekhein: (1) kya sahi chunk top-3 mein aaya? (retrieval ka nateeja) (2) kya final jawab sahi tha? Agar retrieval hi ghalat hai to prompt badalne se faida nahi, pehle retrieval theek karein.

  • Recommendations: milti julti cheezein suggest karna.
  • Duplicate pehchanna: aik hi baat ke alag alfaz.
  • Clustering: text ko mauzu ke hisaab se groups mein baantna.

Fine-tuning gehrai se

  • Full fine-tuning: model ke saare weights badalna. Bohat mehngi aur bari GPU memory chahiye.
  • LoRA jaisay parameter-efficient tareeqay: sirf chhote se extra hissay train hotay hain, kam kharcha, aur aaj zyada tar yehi istemal hota hai.

Training data aam tor par "sawal aur behtareen jawab" ke jore hotay hain:

Data ki quality quantity se zyada ahem hai. 500 saaf, mutanasib aur ghalti se pak misalein 5000 jaldi mein banayi hui misalon se behtar hoti hain. Fine-tuning ke baad model ko un sawalat par bhi jaanchein jo training mein nahi thay, warna aap ko pata nahi chale ga ke model ne ratt liya ya seekha.

Faisla karne ka tareeqa (ek aur nazar)

  1. Pehlay behtar prompt aur misalein likhein. Aksar yehi kaafi hota hai.
  2. Agar model ko aap ka ya taaza data chahiye to RAG lagayen.
  3. Agar makhsoos andaz, chhota model, ya bohat tez/sasta jawab chahiye aur data tayyar hai to fine-tuning sochein.
  4. Zaroorat par teenon aik sath bhi chal sakte hain.

Dhyan: fine-tuning ke baad data ya zaroorat badle to dobara train karna parta hai, jabke RAG mein sirf documents update hotay hain.

Tool calling asal mein kaise hoti hai?

Model khud koi kaam nahi chalata. Aap usay tools ki list dete hain (naam, kaam ki wazahat, aur kaun se inputs chahiyen). Model jawab mein likhta hai "mujhe yeh tool is input ke sath chalana hai". Aap ka code woh tool chalata hai aur natija wapas model ko deta hai. Phir model aagay ka faisla karta hai.

tools = [{
    "name": "get_order_status",
    "description": "Order ID se order ka status batata hai",

        "type": "object",

r = client.messages.create(model="claude-sonnet-5-5", max_tokens=300, tools=tools,
    messages=[{"role": "user", "content": "Mere order 123 ka kya status hai?"}])
for block in r.content:
    if block.type == "tool_use":          # model tool chalane ko keh raha hai
        print(block.name, block.input)    # get_order_status {"order_id": "123"}

Is ke baad aap ka code asal function chalata hai, natija ek tool_result message mein wapas bhejta hai, aur model us se final jawab banata hai. Tool ki wazahat jitni saaf ho, model utna sahi tool chunta hai.

def jawab(sawal):
    q = m.encode([sawal], normalize_embeddings=True)
    ctx = docs[int((D @ q.T).argmax())]
    prompt = ("Sirf is context se jawab do. Agar jawab na ho to kaho 'maloom nahi'.\n\n"
              f"Context: {ctx}\n\nSawal: {sawal}")
    r = client.messages.create(model="claude-sonnet-5-5", max_tokens=300,
        messages=[{"role": "user", "content": prompt}])
    return r.content[0].text

Documents load aur chunk karna

from pypdf import PdfReader

def pdf_text(path):
    return " ".join(p.extract_text() or "" for p in PdfReader(path).pages)

def chunk(text, size=300, overlap=50):
    words = text.split()
    out, i = [], 0
    while i < len(words):
        out.append(" ".join(words[i:i+size]))
        i += size - overlap
    return out

docs = chunk(pdf_text("policy.pdf"))
D = m.encode(docs, normalize_embeddings=True)

Is se aap ka PDF chhote overlapping chunks mein toot kar embeddings ban jata hai (Chapter 19). Scan ki hui tasveer wale PDF mein text nahi hota, un ke liye pehlay OCR chahiye.

Top 3 chunks aur source dikhana

def jawab(sawal):
    q = m.encode([sawal], normalize_embeddings=True)
    scores = (D @ q.T).ravel()
    top = scores.argsort()[::-1][:3]
    ctx = "\n---\n".join(docs[i] for i in top)
    prompt = ("Sirf is context se jawab do. Agar jawab na ho to kaho 'maloom nahi'.\n\n"
              f"Context:\n{ctx}\n\nSawal: {sawal}")

        messages=[{"role": "user", "content": prompt}])
    return r.content[0].text, [int(i) for i in top]   # jawab aur chunk numbers

Privacy: kam se kam data

  • Sirf wohi data lein jo asal mein zaroori ho (data minimization).
  • Naam, phone, CNIC/ID jaisi shinakhti maloomat hataein ya chhupayen (anonymization) jahan mumkin ho.
  • Logon se data lene ki wazeh ijazat (consent) lein aur batayen kis kaam ke liye istemal hoga.
  • Agar data bahar ki service ko nahi bhejna chahtay to local models par ghor karein.

Data aur AI ke qawaneen mulk aur kaam ke hisaab se alag ho sakte hain. Client ya company ke liye kaam karte waqt un ki policy aur apne mulk ke qawaneen khud check karein ya mutaliqa mahir se poochein.

Security ke khatray

  • Prompt injection: ghair mutamad text mein chhupa hukm (Chapter 18, 21).
  • API keys ka leak: code ya screenshot mein key (Chapter 23).
  • Hassas data prompt mein: jo likha jata hai wohi service tak jata hai.

Wazahat aur shafafiyat (transparency)

Jahan AI ka faisla kisi ki zindagi par asar daalta ho (karz, naukri, sehat) wahan wajah batana zaroori hai, aur insan ko faisla badalne ka haq hona chahiye. Apne model ke baare mein aik chhota "model card" likhein: kis data par train hua, kahan achha chalta hai, kahan kamzor hai, aur kin kaamon ke liye istemal nahi karna chahiye.

Launch se pehle checklist

  1. Data kahan se aaya, aur kya us ki ijazat hai?
  2. Groups ke hisaab se nateeja check kiya?
  3. Ghalti ho to sab se bura nuqsan kya hoga?
  4. Insan ki jaanch ya "appeal" ka raasta hai?
  5. User ko pata hai ke woh AI se baat kar raha hai?
  6. Hadood (kamzoriyan) likhi hui hain?

Resource kaise istemal karein

  • Aik waqt mein aik course chunein aur usay mukammal karein.
  • Har video ke baad khud code likhein, sirf copy na karein.
  • Kisi cheez par atakein to pehlay khud 20 minute koshish, phir documentation, phir poochein.
  • Roman Urdu ya Urdu content bhi dekhein, magar technical terms angrezi mein seekhein kyun ke documentation wohi hai.

Resource chunne se pehle 4 sawal

  1. Kya yeh mere level ke liye hai (na bohat asaan, na bohat mushkil)?
  2. Kya is mein khud code likhne wali practice hai?
  3. Kya yeh taaza hai? (AI ke purane tutorials aksar purani libraries istemal karte hain.)
  4. Kya mujhe is ke baad koi cheez banani ayegi?

Documentation kaise parhein?

  1. Quickstart aur "Getting started" pehle, poora manual nahi.
  2. Chhote examples ko apne laptop par chala kar dekhein.
  3. Phir API reference se sirf wohi function dekhein jis ki zaroorat ho.

Research paper ya lambay article ko kaise parhein?

Pehle abstract (khulasa), phir tasveerein aur charts, phir conclusion. Agar aap ko woh kaam ka lagay tab introduction aur tafseel. Har cheez ko mukammal samajhna pehle din zaroori nahi.

Mulk ke hisaab se mauqe

Aap ke aas paas ke masail (zubaan, kheti, chhote kaarobar, e-commerce, maali khidmaat, taleem) aise mauqe hain jahan bahar ki companies ka tayyar-shuda hal kabhi kabhi poori tarah munasib nahi hota. Aap apni zubaan, apne data aur apne logon ke masail samajhte hain, aur yeh aap ki asal taqat ban sakti hai.

AI ke badalte hone par taaza kaise rahein?

  • Hype se ziyada official documentation aur release notes par bharosa karein.
  • 2 se 3 mutamad sources chunein, sab kuch follow karne ki koshish na karein.
  • Har naye tool ke saath aik chhoti cheez khud bana kar dekhein.
  • Hafte mein aik cheez parhein, aik cheez banayen, aur aik cheez kisi se share karein.

Kya aap tayyar hain? Aakhri checklist

  1. Python aur Pandas mein bina dekhe chhoti problem hal kar sakta hoon.
  2. Train/test split, overfitting aur metrics apne alfaz mein samjha sakta hoon.
  3. Kam az kam aik ML aur aik deep learning project mukammal kiya hai.
  4. Token, embedding aur attention ka matlab samajhta hoon.
  5. Aik RAG ya chatbot project banaya aur jaancha hai.
  6. Model ko API ke zariye chalana jaanta hoon.
  7. AI ke khatraat aur hadood (bias, hallucination, privacy) samajhta hoon.
  8. GitHub par saaf README wale 3 projects hain.
  9. CV aur LinkedIn tayyar hain.
  10. Seekhte rehne ki aik aadat bana li hai.

Agar 7 se zyada jawab "haan" hain to aap aagay barhne ke liye tayyar hain. Baaqi cheezein practice se aati rahengi.

Aakhri baat

AI ka field tezi se badalta hai, is liye sab se bari salahiyat seekhne ki aadat hai. Is kitab ne aap ko buniyad aur rasta diya hai, aagay ka safar practice, projects aur sabr se tay hoga. Har din thora sa, lekin lagataar.
