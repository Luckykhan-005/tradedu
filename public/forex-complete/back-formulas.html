تمام فارمولے ایک جگہ (Formulas Cheat Sheet)

یہ کتاب میں استعمال ہونے والے تمام فارمولوں کا مرکزی مجموعہ ہے۔

1. پائپ کی حساب (Pip Calculation)

5-ڈیسمل والے جوڑوں (EUR/USD, GBP/USD, AUD/USD وغیرہ)

1 pip = 0.0001 (چوتھا اعشاریہ)
مثال: 1.0850 → 1.0851 = 1 pip

JPY والے جوڑوں (USD/JPY, GBP/JPY)

1 pip = 0.01 (دوسرا اعشاریہ)
مثال: 149.25 → 149.26 = 1 pip

Pipette (فیکشنل پائپ)

1 pipette = 0.00001 (5-ڈیسمل) یا 0.0001 (JPY)
1 pip = 10 pipettes

2. پائپ ویلیو (Pip Value)

فارمولہ:

Pip Value = (1 pip in decimal) ÷ (Exchange Rate) × (Lot Size in units)

USD-Quoted جوڑوں کے لیے (خریدار = USD):

Pip Value = 0.0001 × Lot Size in units

Standard Lot (100,000):  0.0001 × 100,000 = $10 فی pip
Mini Lot  (10,000):      0.0001 × 10,000  = $1 فی pip
Micro Lot (1,000):       0.0001 × 1,000   = $0.10 فی pip

USD-Base جوڑوں کے لیے (بیس = USD):

Pip Value = (0.01 for JPY or 0.0001) ÷ (Exchange Rate) × (Lot Size in units)

مثال USD/JPY:  ریٹ = 149.25
Pip Value = 0.01 ÷ 149.25 × 100,000 = $6.70 فی pip (Standard Lot)

غیر-USD بیس والے جوڑوں (مثلاً EUR/GBP):

Pip Value = (0.0001) × (Lot Size in units) × (EUR/USD Rate) ÷ (EUR/GBP Rate)

3. پوزیشن سائز (Position Sizing)

فارمولہ:

Lot Size = Risk Amount ÷ (Pip Value × Stop Loss in Pips)

مثال:

اکاؤنٹ:         $2,000
رسک (2%):        $2,000 × 0.02 = $40 (رسک کی رقم)
اسٹاپ لاس:      30 pips
پائپ ویلیو:     $10 (Standard Lot پر)

Lot Size = $40 ÷ ($10 × 30) = $40 ÷ $300 = 0.133 lot → 0.13 lot
تصدیق: 0.13 × $10 × 30 = $39 ≈ $40 ✓

مائیکرو لاٹ پر:

Lot Size = Risk Amount ÷ (Micro Pip Value × Stop Loss in Pips)

مثال: Risk = $40, SL = 30 pips, Micro pip = $0.10
Lot Size = $40 ÷ ($0.10 × 30) = $40 ÷ $3 = 13.33 → 13 micro lots (0.13 lot)

فارمولہ (بیسیس):

پوزیشن سائز = Risk Amount ÷ (Entry - Stop Loss) × (Value per pip)

4. رسک:ریوارڈ (Risk:Reward)

فارمولہ:

R:R = (Take Profit - Entry) ÷ (Entry - Stop Loss)

مثال:

Entry:    1.2850
TP1:      1.2900  (50 pips)
SL:       1.2820  (30 pips)

R:R = 50 ÷ 30 = 1 : 1.67

TP2:      1.2935  (85 pips)
R:R = 85 ÷ 30 = 1 : 2.83 ✅ (بہترین)

منافع کی ضرورت:

R:R = 1:1 → 50% جیت درکار ہے
R:R = 1:1.5 → 40% جیت درکار ہے
R:R = 1:2 → 33.3% جیت درکار ہے
R:R = 1:3 → 25% جیت درکار ہے

فارمولہ: Break Even % = 1 ÷ (1 + R:R) × 100

5. فارمولے کے نمونے (Numerical Examples)

مثال 1: پوزیشن سائز EUR/USD

اکاؤنٹ:       $500
رسک:           1% = $5
جوڑا:          EUR/USD
اسٹاپ لاس:    25 pips
پائپ ویلیو:   $10 (Standard) یا $1 (Mini) یا $0.10 (Micro)

Lot Size = $5 ÷ ($0.10 × 25) = $5 ÷ $2.50 = 2 micro lots (0.02 lot)
تصدیق: 0.02 × $0.10 × 25 = $0.05 — یہ غلط!
صحیح: $5 ÷ ($1 × 25) = 0.20 (Mini Lot = $1 فی pip)
تصدیق: 0.20 × $1 × 25 = $50 — یہ بھی غلط!

اصل صحیح حساب:
پائپ ویلیو 0.01 lot پر = $0.10
$5 ÷ ($0.10 × 25) = $5 ÷ $2.50 = 2 (مائیکرو لالٹ = 0.02)
تصدیق: 0.02 × 10,000 = 200 units × $0.10 × 25 = ...

اچھا:
1 Micro Lot = 1,000 units
1 pip ($0.10 per micro lot)
25 pips × $0.10 = $2.50 risk per micro lot
$5 risk ÷ $2.50 = 2 micro lots = 0.02 lot ✓

مثال 2: رسک:ریوارڈ GBP/USD

Entry:      1.2500
SL:         1.2450 (50 pips)
TP1:        1.2600 (100 pips)
TP2:        1.2650 (150 pips)

R:R TP1 = 100 ÷ 50 = 1 : 2 ✅
R:R TP2 = 150 ÷ 50 = 1 : 3 ✅

مثال 3: مارجن کی حساب (Margin Calculation)

اکاؤنٹ:        $1,000
لیوریج:         1:100
جوڑا:           EUR/USD
Lot:             1.00 (Standard = 100,000 units)
ریٹ:             1.0850

پوزیشن ویلیو = 100,000 × 1.0850 = $108,500
Required Margin = $108,500 ÷ 100 = $1,085

اکاؤنٹ $1,000 میں پوزیشن نہیں کھول سکتے — لیوریج کم کریں یا سائز کم کریں!

مثال 4: نقصان اور منافع کی حساب

Trade:          EUR/USD
Direction:      BUY
Entry:          1.0850
SL:             1.0820 (30 pips risk)
TP:             1.0900 (50 pips reward)
Lot:            0.10 (Mini = 10,000 units)
Pip Value:      $1 فی pip (Mini lot, USD-quote)

Risk:     30 × $1 = $30 (اکاؤنٹ کا 1.5% — صحیح)
Reward:   50 × $1 = $50
R:R:      1 : 1.67

If 50% win rate with 1:1.67 R:R:
50 wins × $50 = $2,500 gross
50 losses × $30 = $1,500 gross loss
Net = $1,000 profit (on 100 trades) ✅

مثال 5: ڈرا ڈاؤن کی حساب

اکاؤنٹ بلند:    $12,000 (Peak)
اکاؤنٹ کم:      $9,600 (Trough)

Drawdown = (Peak - Trough) ÷ Peak × 100
         = (12,000 - 9,600) ÷ 12,000 × 100
         = 2,400 ÷ 12,000 × 100
         = 20%

واپسی کے لیے مطلوبہ منافع:
= (1 ÷ (1 - 0.20) - 1) × 100
= (1 ÷ 0.80 - 1) × 100
= (1.25 - 1) × 100
= 25%

مثال 6: ڈیلی لاسٹ لمٹ

اکاؤنٹ:     $5,000
ڈیلی حد:    3% = $150

ٹریڈ 1: -$60 → اکاؤنٹ: $4,940
ٹریڈ 2: -$90 → اکاؤنٹ: $4,850
کل نقصان:    -$150 = 3% → حد پوری! ⛔ ٹریڈنگ بند

6. لیوریج اور مارجن (Leverage & Margin)

لیوریج فارمولہ:

Leverage = Position Value ÷ Required Margin
مثال: $100,000 ÷ $1,000 = 1:100

Required Margin:

Required Margin = Position Value ÷ Leverage
مثال: $100,000 ÷ 100 = $1,000

Free Margin:

Free Margin = Account Equity - Used Margin

Margin Level:

Margin Level = (Equity ÷ Used Margin) × 100%
اگر Margin Level < 100% → Margin Call

لیوریج جدول (اکاؤنٹ $1,000 پر):

لیوریجMax PositionPip Risk (1 lot)
1:30$30,000$1,000 per pip (dangerous)
1:100$100,000$100 per pip
1:200$200,000$50 per pip
1:500$500,000$20 per pip
