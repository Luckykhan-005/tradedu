باب 3: Pip, Lot, Spread — قیمت اور حجم کی زبان

فارکس میں منافع اور نقصان پِپس میں ناپا جاتا ہے، ٹریڈ کا حجم لاٹس میں، اور ٹریڈ کھولنے کی قیمت اسپریڈ میں۔ یہ تین تصورات سمجھے بغیر کوئی حساب درست نہیں ہو سکتا۔ یہ فارکس کی "ریاضی" ہے — اور اسے آج ہی پکی کر لیں۔

🎯 اس باب میں آپ سیکھیں گے

  • Pip اور Pipette کیا ہیں
  • Pip Value کا حساب لگانا (USD اور غیر-USD اکاؤنٹس)
  • Lot (Standard, Mini, Micro) اور Contract Size
  • Leverage کا جائزہ (تفصیل باب 4/حصہ 7 میں)
  • Spread کیا ہے — اور آپ اسے کیوں ادا کرتے ہیں
  • Margin اور Free Margin کا تعارف
  • ایک مکمل مثال: پورا حساب ایک ساتھ

📖 3.1 Pip کیا ہے؟

Pip = Percentage In Point — قیمت میں حرکت کی سب سے چھوٹی معیاری اکائی۔

دو اصول (بہت اہم)

جوڑاایک Pip کہاں ہوتا ہے؟مثال
5-ڈیسمل والے (EUR/USD, GBP/USD وغیرہ)4th اعشاریہ (0.0001)1.0850 → 1.0851 = 1 pip اوپر
JPY والے (USD/JPY, GBP/JPY)2nd اعشاریہ (0.01)149.25 → 149.26 = 1 pip اوپر

مثال EUR/USD

قیمت بدلتی ہے:  1.08500  →  1.08510  →  1.08600
pip حرکت:                    +1 pip        +10 pips

Pipette (پائپیٹ / Fractional Pip)

زیادہ تر بروکرز اب قیمت 5 اعشاریہ (JPY میں 3) دکھاتے ہیں۔ آخری چھوٹا ہندسہ pipette کہلاتا ہے (Pip کا 1/10)۔

1.08500  ← یہاں 1.0850 = pip، آخری "0" = pipette

💡 تجارتی فائدہ: پائپیٹ بروکر کو کم اسپریڈ دکھانے دیتا ہے (مثلاً 0.8 pip کی بجائے 8 pipette)۔ اصل بات پِپس پر توجہ رکھیں۔

📖 3.2 Pip Value (ایک Pip کی قیمت) — USD اکاؤنٹ کے لیے

یہ سب سے اہم حساب ہے: ایک pip چلنے پر آپ کو کتنے ڈالر ملتے/جاتے ہیں؟

اصول: Pip Value = (1 pip کی اعشاریہ قیمت) ÷ (موجودہ ریٹ) × (Lot Size in units)

کیس 1: USD کوٹ کرنسی والے جوڑے (EUR/USD, GBP/USD, AUD/USD…)

ان میں USD دوسری (کوٹ) کرنسی ہے، اس لیے حساب سیدھا ہے:

  • 1 standard lot = 100,000 units
  • 1 pip = 0.0001
  • Pip value = 0.0001 × 100,000 = $10 فی pip (ہر standard lot پر)
حجمLot TypeUnits$ فی pip (USD-quote جوڑے)
1.00Standard100,000$10
0.10Mini10,000$1
0.01Micro1,000$0.10

کیس 2: USD بیس کرنسی والے جوڑے (USD/JPY, USD/CHF, USD/CAD…)

یہاں USD پہلی (بیس) ہے، اس لیے pip value ریٹ پر منحصر ہے:

  • USD/JPY: 1 pip = 0.01۔ اگر ریٹ 149.25 ہے:
    • Pip value (فی lot) = 0.01 ÷ 149.25 × 100,000 = $6.70 فی pip
  • ریٹ بدلنے سے pip value بھی بدلتی ہے (149 پر ~$6.70، 155 پر ~$6.45)۔

💡 بروکرز اور کیلکولیٹرز یہ سب خود کرتے ہیں، مگر آپ کو سمجھنا ضروری ہے تاکہ بروکر کی کوئی غلطی/کمی نظر آئے۔

📖 3.3 Lot (لاٹ) — ٹریڈ کا حجم

Lot ٹریڈ کی معیاری مقدار ہے۔ تین عام اقسام:

قسمUnitsمناسب کس کے لیے
Standard Lot100,000بڑے سرمائے والے
Mini Lot10,000درمیانے اکاؤنٹس
Micro Lot1,000ابتدائی تاجر / چھوٹے اکاؤنٹس

⚠️ نصیحت: نئے تاجر اکثر "standard lot" کھول کر بڑا نقصان کرتے ہیں کیونکہ وہ فی pip $10 کی قیمت سمجھ نہیں پاتے۔ پہلے مہینوں میں micro lot (0.01) ہی استعمال کریں۔

📖 3.4 Spread (اسپریڈ) — آپ کی "انٹری فیس"

Bid اور Ask

ہر جوڑے کی دو قیمتیں ہوتی ہیں:

  • Bid: جس قیمت پر آپ بیچ سکتے ہیں (خریدار کی قیمت)۔
  • Ask: جس قیمت پر آپ خرید سکتے ہیں (بیچنے والے کی قیمت)۔
Ask: 1.0851   (آپ یہاں BUY کرتے ہیں)
Bid: 1.0849   (آپ یہاں SELL کرتے ہیں)
Spread = Ask − Bid = 2 pips
  • Spread ان دونوں کا فرق ہے — یہ بروکر/مارکیٹ میکر کی فیس ہے۔
  • آپ ٹریڈ کھولتے ہی فوراً اسپریڈ کے برابر منفی میں ہوتے ہیں۔
  • EUR/USD پر اسپریڈ اکثر 0.0–0.5 pip (RAW/ECN اکاؤنٹ) یا 1 pip تک ہوتی ہے۔ GBP/JPY پر 1-3 pips، ایکزوٹک پر 20+ pips ہو سکتی ہے۔

📊 کمیں (Commissions): ECN/RAW اکاؤنٹس میں اسپریڈ بہت کم مگر فی لاٹ کمیشن لگتا ہے (جیسے $3.5 فی side)۔ Standard اکاؤنٹس میں کوئی کمیشن نہیں، مگر اسپریڈ زیادہ۔ دونوں کا خالص اثر اکثر برابر ہوتا ہے — لیکن آپ کو معلوم ہونا چاہیے۔

📖 3.5 Margin اور Leverage — تعارف

  • Leverage (لیوریج): بروکر کی دی ہوئی قوت خرید۔ 1:100 کا مطلب: $1 پر $100 کی پوزیشن۔
  • Margin (مارجن): وہ رقم جو پوزیشن کھولنے کے لیے "ضمانت" کے طور پر روک لی جاتی ہے۔
اکاؤنٹ: $1,000    لیوریج: 1:100
آپ 1.00 lot EUR/USD کھولنا چاہتے ہیں = $100,000 پوزیشن
Required Margin = $100,000 ÷ 100 = $1,000

⚠️ اس مثال میں آپ کا پورا اکاؤنٹ مارجن بن گیا — کوئی بفر نہیں۔ لیوریج کا صحیح استعمال حصہ 7 کا موضوع ہے۔ ابھی صرف تصور یاد رکھیں۔

Margin Levels (جھلکی)

  • Used/Required Margin: پوزیشن کھولنے کے لیے روکی گئی رقم۔
  • Free Margin: وہ رقم جو نئی پوزیشن کے لیے دستیاب ہے۔
  • Margin Call / Stop Out: جب اکاؤنٹ اتنا نقصان کرے کہ مارجن پورا نہ ہو — بروکر پوزیشن زبردستی بند کر دیتا ہے (حصہ 7 میں مکمل تفصیل)۔

📖 3.6 ایک مکمل مثال — سارا حساب ایک ساتھ

منظر: EUR/USD پر BUY

چیزتفصیل
ریٹ (Ask)1.08500
Lot0.10 (Mini = 10,000 units)
لیوریج1:100
اکاؤنٹ$500

حساب 1 — پوزیشن ویلیو: 10,000 × 1.0850 = $10,850

حساب 2 — Required Margin: $10,850 ÷ 100 = $108.50

حساب 3 — Pip Value: 0.0001 × 10,000 = $1 فی pip

حساب 4 — منافع کا منظر: قیمت 1.0850 → 1.0900 (50 pips اوپر)

  • منافع = 50 pips × $1 = $50 (اکاؤنٹ کا 10%)

حساب 5 — نقصان کا منظر: قیمت 1.0800 تک (50 pips نیچے)

  • نقصان = 50 pips × $1 = $50 (اکاؤنٹ کا 10%)

💡 دیکھیں: صرف 50 pip کی حرکت سے اکاؤنٹ کا 10% لہو — اسی لیے رسک مینجمنٹ (حصہ 7) سب سے اہم ہے۔

📖 3.7 "Swap" (سواپ / راتوں رات فیس)

اگر آپ پوزیشن رات بھر (اگلے دن تک) رکھتے ہیں تو بروکر آپ سے/کو Swap (Rollover Interest) لیتا ہے:

  • دو کرنسیوں کی شرحِ سود کا فرق۔
  • اگر آپ زیادہ شرحِ سود والی کرنسی BUY کرتے ہیں تو آپ کو ملتا ہے؛ ورنہ آپ دیتے ہیں۔
  • مقدس (Islamic) اکاؤنٹس میں swap نہیں ہوتی (شرعی رہنمائی حصہ 8 میں)۔

⚠️ باب 3 کی عام غلطیاں

  1. Pip اور Point میں الجھنا: Point بعض اوقات pipette کے لیے بولا جاتا ہے — ہمیشہ تصدیق کریں کہ آپ کا بروکر کس کو pip کہتا ہے۔
  2. Lot size سمجھے بغیر ٹریڈ: 1.00 lot فی pip $10 ہے — بغیر حساب کے یہ اکاؤنٹ ختم کر سکتا ہے۔
  3. Spread کو نظر انداز کرنا: ٹریڈ کھلتے ہی آپ spread کے برابر "نیچے" ہوتے ہیں — خاص کر سکیلپرز کے لیے اہم۔
  4. صرف leverage دیکھ کر خوش ہونا: بڑا لیوریج = بڑا مارجن خطرہ، اگر پوزیشن سائزنگ غلط ہو۔

✅ خلاصہ (Key Takeaways)

  • Pip: EUR/USD جیسے جوڑوں میں 4th decimal؛ JPY جوڑوں میں 2nd decimal۔
  • Pip Value: USD-quote جوڑوں میں فی standard lot = $10؛ USD-base جوڑوں میں ریٹ کے لحاظ سے۔
  • Lot: Standard 100k، Mini 10k، Micro 1k۔ ابتدا میں Micro۔
  • Spread: Bid اور Ask کا فرق = آپ کی انٹری فیس۔
  • Margin: پوزیشن کے لیے ضمانت۔ Leverage: قوت خرید۔
  • پوزیشن سائزنگ کے بغیر کوئی ٹریڈ نہ کریں۔

📝 عملی مشق

  1. اپنے ڈیمو اکاؤنٹ پر EUR/USD کھولیں (0.01 lot)۔ دیکھیں: آپ کا فوری P&L کیا دکھا رہا ہے؟ (یہی آپ کی spread ہے)۔
  2. USD/JPY پر بھی 0.01 lot کھولیں۔ دونوں کی pip value خود حساب کریں اور بروکر کی ونڈو سے ملائیں۔
  3. ایک کاغذ پر لکھیں: آپ کے $300 اکاؤنٹ پر 0.50 lot کھولنے پر فی pip قیمت کتنی ہوگی؟ (0.0001 × 50,000 = $5)۔ کیا یہ عقلمندی ہے؟ کیوں/کیوں نہیں؟

🧠 یاد رکھیں

جو شخص pip، lot اور spread کا حساب نہیں جانتا، وہ جوا کھیل رہا ہے — چاہے اس کا چارٹ تجزیہ کتنا بھی اچھا ہو۔
